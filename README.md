# *Pass Platform

Платформа управления доступом на открытом ПО — три продукта, один стек.

## Продукты

| Продукт | Сценарий | Стоимость |
|---------|---------|---------|
| **HomePass** | Умный дом, частный дом, local-first | от 34 000 ₽ DIY |
| **CloudPass** | Малый бизнес, сети объектов, без своего сервера | от 990 ₽/мес |
| **TenantPass** | Корпоративный СКУД + СУРВ, on-premise | от 460 000 ₽ |

## Принципы

- Открытый исходный код (Apache 2.0 / MIT)
- Данные остаются у клиента — никаких обязательных облаков
- Работает без интернета (offline-кэш на устройствах)
- ML из коробки: биометрия, LPR, tailgating-детекция
- 152-ФЗ, ФСТЭК, ТК РФ — закрыты архитектурно

## Собственные устройства

- **DN·Beacon** — BLE-маяк nRF52832, AES-128 динамический ID, IP67, 10 лет от батареи
- **DN·LoRaWAN** — датчики SX1262 + nRF52840, 20 км, RU868
