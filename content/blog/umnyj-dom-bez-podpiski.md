Большинство «умных» устройств на рынке — это подписка. Xiaomi, Яндекс, Amazon: всё работает через их облако. Отключили сервер — погас свет. Компания обанкротилась — все устройства стали кирпичами. Данные о вашем доме — на их серверах.

Есть альтернатива: полностью локальная система, которая работает без интернета, без подписки и без доступа третьих лиц к данным о вашей жизни.

---

## Что такое HomePass

HomePass — это комплексная автоматизация частного дома на базе **Home Assistant**: единой платформы с открытым кодом, которую используют более 500 000 домов по всему миру.

Принцип:
- Все данные хранятся **у вас дома** на локальном сервере
- Интернет нужен только для удалённого доступа со смартфона, но не для работы системы
- При отключении провайдера дом продолжает работать в обычном режиме

## Что умеет система

### Безопасность и доступ

| Функция | Как работает |
|---------|-------------|
| Видеонаблюдение | 6–8 камер по периметру, AI-детекция людей, запись 24/7 |
| Умный замок на воротах | BLE-смартфон → ворота открываются без касания при подъезде |
| Гостевой доступ | Временный QR-код для гостей или подрядчиков (действует N часов) |
| Тревога | Датчики движения → сирена + уведомление на телефон |
| Пожар/CO | Датчик → отключение газа + SMS |

### Климат и отопление

| Функция | Как работает |
|---------|-------------|
| Умный котёл | Расписание + погода → экономия 15–25% газа |
| Тёплый пол по зонам | Каждая комната — независимо |
| Теплица | Автоматический полив по влажности грунта + вентиляция |
| Подвал/котельная | Мониторинг температуры, давления, затопления |

### Освещение и электрика

| Функция | Как работает |
|---------|-------------|
| Умные выключатели | Shelly/Sonoff: физический выключатель + приложение + голос |
| Сценарии | «Уходим» → всё выключается, замок закрывается, сигнализация включается |
| Учёт электроэнергии | Каждая розетка/линия — измерение потребления |
| Резервное питание | UPS на 18650 → Raspberry Pi работает 8 часов без света |

## Поддерживаемые устройства

Система работает с любыми устройствами через открытые протоколы:

- **Zigbee** — датчики температуры, движения, открытия окон/дверей (батарейки 2–5 лет)
- **WiFi** — Shelly, Sonoff, ESPHome (DIY на ESP32)
- **Z-Wave** — европейские устройства высокого класса
- **BLE** — присутствие, замки, DN·Beacon
- **MQTT** — любые самодельные датчики

**Не нужно** покупать устройства одного производителя. Можно смешивать.

## Строения и зоны

Система покрывает весь участок, не только дом:

```
Основной дом
  ├── Жилые зоны: освещение, климат, шторы
  ├── Котельная/подвал: мониторинг безопасности
  └── Чердак: температура, солнечные панели

Хозяйственные постройки
  ├── Гараж: ворота, сигнализация, освещение
  ├── Баня: предподготовка температуры по расписанию
  └── Теплица: полив, вентиляция, освещение

Периметр
  ├── Ворота + калитка: умный замок, домофон
  └── Видеонаблюдение: 360° покрытие
```

## ML в умном доме: система учится вашим привычкам

Опциональный уровень:

- **Распознавание жильцов** по лицу или BLE: ворота открываются до того, как вы нажали кнопку
- **Прогноз возврата домой**: система предсказывает за 20 минут что вы едете — включает отопление, разогревает баню
- **Детекция незнакомцев**: ночью на участке — кто-то чужой → тревога
