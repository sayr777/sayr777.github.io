DN·Beacon — собственная разработка для задач, где карточку RFID могут передать другому человеку. Маяк работает по BLE с динамически меняющимся шифрованным ID: каждую сессию устройство генерирует новый идентификатор, который нельзя перехватить и воспроизвести.

## Технические характеристики

| Параметр | Значение |
|----------|---------|
| Чип | nRF52832 |
| Протокол | BLE 5.0 |
| Защита | AES-128, динамический ID (rolling code) |
| Дальность | до 70 м на открытом пространстве |
| Батарея | CR2032, до 10 лет в стандартном режиме |
| Корпус | IP67 — пыль и вода |
| Рабочая температура | −55…+85°C |
| Размер | 35 × 35 × 8 мм |

## Режимы работы

- **Пропуск** — замена карточки RFID. Контроллер верифицирует подпись; клонирование невозможно.
- **Трекер присутствия** — система фиксирует нахождение сотрудника в зоне (зональный учёт рабочего времени).
- **Кнопка SOS** — однократное нажатие отправляет тревогу на пульт охраны с идентификатором носителя.

## Сценарии применения

- Производственные предприятия: замена карточек, зональный СУРВ
- Стройки: трекинг бригад, контроль доступа в опасные зоны
- Больницы: идентификация персонала без необходимости снимать перчатки
- Умный дом: открытие ворот / дверей при приближении жильца

## Защита от подмены

В отличие от RFID-карт с фиксированным UID (которые можно скопировать за 2 секунды), DN·Beacon меняет идентификатор при каждом сеансе связи. Контроллер проверяет HMAC-подпись с ключом, хранящимся только на устройстве и в защищённой памяти контроллера.
