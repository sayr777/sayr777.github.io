DN·LoRaWAN решает задачу мониторинга удалённых точек, куда нельзя провести кабель и нерентабельно тянуть WiFi: периметр стройки, склад за городом, резервуары, вышки, подстанции.

## Технические характеристики

| Параметр | Значение |
|----------|---------|
| Чипы | SX1262 (LoRa) + nRF52840 (MCU) |
| Протокол | LoRaWAN 1.1 OTAA |
| Диапазон | RU868 (законный в России) |
| Дальность | до 20 км от шлюза на открытом пространстве |
| Шифрование | AES-128 end-to-end |
| Батарея | 3.6В Li-SOCl₂, до 10 лет при 1 пакете в час |
| Корпус | IP67 |
| Рабочая температура | −40…+85°C |

## Типы датчиков в линейке

| Модель | Что измеряет |
|--------|-------------|
| DN·LoRaWAN-T | Температура + влажность |
| DN·LoRaWAN-D | Открытие двери / ворот |
| DN·LoRaWAN-M | Движение в зоне |
| DN·LoRaWAN-P | Давление, затопление |

## Схема работы

```
Датчик → LoRaWAN Gateway → ChirpStack → MQTT → TenantPass
```

Шлюз (gateway) накрывает радиус до 20 км: один шлюз на всю промышленную зону или стройку. Данные идут в ChirpStack LNS, оттуда по MQTT в платформу.

## Сценарии применения

- Мониторинг доступа на периметре стройки (десятки точек, километры расстояний)
- Контроль резервуаров, складов ГСМ
- Сигнализация на дачных и коттеджных посёлках без проводки
- Мониторинг состояния удалённого оборудования
