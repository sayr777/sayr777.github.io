EventPass — Архитектура

EventPass — Архитектура

Принципы

Облако = единственный вариант. Нет серверного оборудования у клиента. Максимум — мобильный считыватель или планшет на входе.

Жизненный цикл тенанта: создан → активен → архивирован. Мероприятие живёт часы или недели, а не годы.

Идентификация без инфраструктуры: QR-код на экране телефона / распечатанный на билете. Нет Wiegand-турникетов в большинстве случаев (исключение — стройплощадка и стадион).

Тенант = Мероприятие

Каждое мероприятие — отдельная Keycloak Organization.

Организатор "Стадион Лужники":
  Organization: luzhniki
    └── Event: match-2026-10-20   (тенант)
         ├── Realm Groups: fans, vip, press, staff, security
         └── Zones: sector_a, sector_b, vip_lounge, backstage

Организатор "Стройкомпания Альфа":
  Organization: alpha-stroy
    └── Event: site-spb-2026      (тенант)
         ├── Realm Groups: brigade_1, brigade_2, contractors, management
         └── Zones: zone_a, zone_b, office, danger_zone

После архивирования данные тенанта доступны только для чтения (аналитика).

Жизненный цикл мероприятия

1. SETUP (T-7 дней до мероприятия)
   Организатор создаёт мероприятие:
     - Название, дата, продолжительность
     - Описание зон и правил доступа
     - Список участников (CSV / интеграция с билетной системой)

2. ONBOARDING (T-1 день — T-2 часа)
   Участники получают QR-коды:
     - Email / SMS / push в приложении организатора
     - Мобильная регистрация (selfie + имя + телефон)
     - Групповая регистрация через организатора

3. ACTIVE (во время мероприятия)
   Считыватели на входе сканируют QR:
     - Онлайн: запрос в EventPass API → permit/deny
     - Оффлайн: кэш разрешений за последние 15 мин

4. COOLDOWN (T+2 часа после окончания)
   - Новые входы блокируются
   - Данные доступны для скачивания 30 дней

5. ARCHIVE (T+30 дней)
   - Автоматическое архивирование
   - PII-данные удаляются (GDPR / 152-ФЗ)
   - Агрегированная статистика хранится 1 год

Считыватель на входе

Вариант 1: Планшет с приложением (self-service)

Android-планшет (10") + QR-считыватель (USB/Bluetooth)
Крепление: стойка или барьер

Возможности:
  - Сканирует QR → мгновенный ответ (зелёный/красный экран + звук)
  - Фото при входе (опционально, с согласия)
  - Самостоятельная регистрация (участник вводит код из SMS)
  - Оффлайн-режим: кэш до 15 минут, 10 000 разрешений

Вариант 2: Портативный считыватель (стройка / спорт)

ESP32 + 4G-модем + QR-сканер + LED-индикатор
Питание: аккумулятор 12 ч
Крепление: турникет, шлагбаум, ручной сканер охраны

REST API:
  POST /api/v1/events/{event_id}/check-in
  {
    "qr_token": "ep_abc123",
    "zone_id": "sector_a",
    "device_id": "scanner-042"
  }
  →  {"status": "permit", "name": "Иван И.", "zone": "Сектор A"}
  →  {"status": "deny", "reason": "wrong_zone", "allowed": ["sector_b"]}

Вариант 3: NFC-браслет (фестиваль / корпоратив)

RFID/NFC браслет с балансом (для оплаты на мероприятии) + доступ к зонам
Выдаётся на входе при регистрации, привязывается к QR-заявке
