EventPass для стройплощадки

EventPass для стройплощадки

Задача

Стройплощадка — временный объект с высокой ротацией людей, несколькими подрядчиками, опасными зонами и жёсткими требованиями по охране труда.

Главная боль: подрядчик прислал бригаду — кто вообще пришёл? Все ли прошли инструктаж? Кто находится в опасной зоне прямо сейчас?

Целевая аудитория

  • Генподрядчик (ведёт весь объект)
  • Субподрядчики (несколько организаций на одном объекте)
  • Застройщик / технадзор (контроль)
  • Проектные организации (временные визиты)

Структура объекта

Стройплощадка "ЖК Северный, корпус 1":
  Зоны:
    checkpoint     — КПП (все проходят)
    area_a         — Корпус А (бетонщики, монтажники)
    area_b         — Корпус Б (отделочники)
    crane_zone     — Зона работы кранов (только авторизованные + сигнальщики)
    electrical     — Электрощит / ИБП-помещение (только электрики)
    office         — Прорабская (прорабы + менеджмент)
    canteen        — Столовая (все)

  Подрядчики (Organizations):
    monolith_llc   — Монолитстрой: зоны area_a, area_b
    mechanic_llc   — МехСтрой: зоны crane_zone
    electric_llc   — ЭлектроМонтаж: зоны electrical
    finish_llc     — ОтделкаПро: зона area_b

Ключевые сценарии

Сценарий 1: Новая бригада — первый приход

Прораб Монолитстроя создаёт группу "Бригада Иванова" в приложении:
  → Добавляет 12 человек (ФИО + телефон)
  → Отмечает: "инструктаж по ОТ пройден 18.10.2026"
  → Назначает зоны: area_a

Каждый рабочий получает SMS:
  "Вам выдан пропуск на стройплощадку ЖК Северный.
   Для входа предъявите QR-код: [ссылка]
   Действует: 18.10 — 30.11.2026"

На КПП:
  Рабочий показывает QR → охранник сканирует
  → EventPass: ✅ допуск действителен, инструктаж в порядке
  → Считыватель разрешает вход

Сценарий 2: Истечение инструктажа по охране труда

Срок инструктажа — 6 месяцев.

Система за 7 дней:
  → Push прорабу: "У 5 рабочих истекает допуск по ОТ 25 октября"
  
В день Х:
  Рабочий подходит к турникету КПП
  → EventPass: ❌ deny — допуск по ОТ истёк
  → Сообщение охраннику: "Требуется повторный инструктаж"
  
Прораб проводит инструктаж:
  → Отмечает в приложении → доступ восстановлен мгновенно

Сценарий 3: Экстренный учёт (пожар / ЧС)

Сигнал пожарной тревоги:
  → EventPass автоматически:
    1. Переходит в режим "Эвакуация"
    2. Разблокирует все турникеты и двери (fail-safe open)
    3. Начинает фиксировать покидающих периметр

На экране прораба / начальника охраны:
  ┌─────────────────────────────────────────────────┐
  │  ЭВАКУАЦИЯ — 14:23:07                           │
  │                                                 │
  │  Покинули объект: 87 / 102                      │
  │                                                 │
  │  НА ОБЪЕКТЕ (не вышли):                         │
  │  ⚠ Иванов А.Н. — зона area_a (корпус А, 7 эт) │
  │  ⚠ Петров С.В. — зона crane_zone               │
  │  ⚠ Ким В.Л.   — зона electrical                │
  └─────────────────────────────────────────────────┘

Список передаётся спасателям.

Сценарий 4: Технадзор — разовый визит

Инспектор от заказчика приезжает на проверку:
  Прораб за 5 мин до визита:
    → Приложение → "Создать гостевой пропуск"
    → Имя, телефон, доступные зоны, срок: "сегодня до 18:00"
    → Инспектор получает SMS с QR-кодом

  На КПП: сканирует QR → вход разрешён
  После 18:00: QR автоматически деактивируется

Реестр допусков

Для каждого рабочего хранится:

ДопускСрокСтатус

Первичный инструктаж на рабочем местеОднократно✅/❌
Работа на высоте (4 категория риска)1 год✅/❌
Стропальщик (удостоверение)1 год✅/❌
Электробезопасность (группа)1 год✅/❌
Медосмотр1 год✅/❌
Иностранный гражданин (разрешение на работу)Дата истечения✅/❌

Без действующих допусков — вход заблокирован автоматически.

Кто видит что

platform_admin (EventPass):       все объекты
site_manager (Генподрядчик):      весь объект — все подрядчики, все зоны
contractor_admin (Прораб суб-):   только свои бригады, свои зоны
worker (Рабочий):                 собственный QR, свои смены
security_officer:                 весь объект — просмотр, не редактирование
inspector (Технадзор):            временный пропуск, аналитика по запросу

Отчётность для генподрядчика

Ежедневный отчёт (автоматически в 21:00):
  - Кол-во рабочих по подрядчикам
  - Трудодни по зонам
  - Нарушения (попытки входа в недоступную зону)
  - Просроченные допуски

Месячный отчёт:
  - Человеко-часы по подрядчику (для расчёта с субподрядчиком)
  - Динамика численности
  - Инциденты и нарушения

Оборудование

КПП (основной вход):
  Стационарный турникет + считыватель QR/RFID
  Монитор охранника с дашбордом

Зональные точки (crane_zone, electrical):
  Накладной считыватель QR (IP65, уличный) + рилейный выход на замок
  Питание: 220В или Power over Ethernet

Мобильная версия:
  Охранник на объезде сканирует QR через мобильное приложение
  Работает без постоянного покрытия (оффлайн-кэш 30 мин)

Выбор типа турникета

ТипПропускная способностьПрименение на стройке
Трипод (PERCo, Came)15–25 чел/минКПП до 200 чел/смену — оптимально
Полноростовой10–15 чел/минРежимный периметр, ночная охрана
Speed gate35–60 чел/минКрупная стройка от 500 чел
Электрозамок + калитка—Электрощитовая, склад, подсобки
Шлагбаум DoorHan + LPR—Въезд техники и авто

Все варианты интегрируются по Wiegand 26/34 или OSDP — считыватели QR, BLE, биометрия подключаются напрямую.
