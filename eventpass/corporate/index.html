EventPass для корпоратива

EventPass для корпоратива

Задача

Корпоративное мероприятие компании: новогодний праздник, командный выезд, конференция, тимбилдинг. Участники — сотрудники (из разных офисов и городов), VIP-гости (партнёры, руководство), сопровождение (плюс-один).

Главная боль: HR отправила список в Excel, секьюрити площадки его не видит, на входе стоит очередь из людей с распечатанными приглашениями.

Особенности сегмента

  • Участники известны заранее (список сотрудников из HR-системы)
  • Часто несколько статусов: обычный гость / VIP / спикер / орг-команда
  • Рассадка (столы, банкетные зоны) — нужна интеграция
  • Мероприятие разовое, повторно платить за сложную настройку не хочется
  • Регистрация гостей на месте — без очереди

Роли и зоны

Роли:
  employee        — сотрудник компании
  vip_guest       — VIP-гость / партнёр
  plus_one        — сопровождение (+1 к билету)
  speaker         — спикер / участник сцены
  organizer       — орг-команда
  security        — охрана (внешняя, площадки)
  vendor          — кейтеринг, техники, DJ

Зоны (пример новогоднего корпоратива):
  main_hall       — банкетный зал (все гости)
  vip_table       — VIP-столы (vip_guest + speaker)
  backstage_stage — за сценой (speaker + organizer)
  photo_zone      — фотобудка / фотограф (все)
  after_party     — афтепати (отдельный список)

Ключевые сценарии

Сценарий 1: Импорт списка из HR-системы

HR-менеджер:
  1. Скачивает список сотрудников из 1С:ЗУП / SAP / BambooHR (CSV)
  2. Загружает в EventPass
  3. Отмечает VIP-гостей вручную
  4. Добавляет внешних гостей (имя + email/телефон)
  
EventPass:
  → Рассылает приглашения всем (email + SMS)
  → Каждый получает персональный QR-код
  → В приглашении: программа мероприятия + схема проезда

Сценарий 2: Регистрация “плюс-один”

Сотрудник получил приглашение с правом взять +1:

Сотрудник в приложении EventPass:
  → "Добавить сопровождение" → вводит имя партнёра
  → Партнёр получает отдельный QR-код (зона: main_hall, без VIP)

На входе:
  Оба сканируются отдельно
  QR сотрудника: ✅ employee + все разрешённые зоны
  QR партнёра: ✅ plus_one + main_hall only

Сценарий 3: Регистрация на месте без приглашения

Гость забыл / не получил QR:

Стойка регистрации (планшет с приложением):
  Оператор ищет по фамилии или номеру телефона
  → "Иванов Алексей" → найден → отправить QR на телефон
  → Гость показывает QR из SMS → вход

Гость не в списке:
  → Менеджер мероприятия одобряет на месте (один клик в приложении)
  → QR генерируется немедленно

Сценарий 4: Параллельные зоны (конференция)

Деловая конференция:
  09:00–12:00: Пленарная сессия (зал А) — все участники
  12:00–13:00: Обед (ресторан, отдельная зона) — только зарегистрированные
  13:00–17:00: Секции (залы Б, В, Г) — выбирает сам участник
  18:00–20:00: Нетворкинг-ужин — только по приглашению (250 чел из 500)

EventPass:
  Участник сам выбирает секции при регистрации
  QR-код адаптируется под выбранные секции
  На входе в зал Г: считыватель проверяет — записан ли на эту секцию

Сценарий 5: Аналитика для HR

После мероприятия HR получает:

Отчёт посещаемости:
  Всего приглашено: 350
  Пришло: 287 (82%)
  VIP-гости: 28/30 (93%)
  Не пришли без предупреждения: 12 чел

По подразделениям:
  Продажи: 45/48 (94%)
  IT: 31/40 (78%)
  Финансы: 22/30 (73%)

Время прихода:
  18:00–19:00: 124 чел (пик)
  19:00–20:00:  98 чел
  20:00+:        65 чел (опоздали)

Интеграция с рассадкой

Если площадка предоставляет схему рассадки:

EventPass:
  QR-код → при сканировании на входе выводит: "Ваш стол: 12, место: 3"
  
Официанты:
  Планшет с картой зала + список по столам
  → видят кто за каким столом, пришёл / не пришёл

Гость опоздал:
  → QR просроченный (если задан жёсткий дедлайн) — нет, такого нет
  → QR работает весь вечер, официант пересаживает

Ценообразование

Корпоратив — разовое мероприятие:

  до 100 чел:   2 500 ₽ (разовый)
  до 300 чел:   5 000 ₽
  до 1 000 чел: 12 000 ₽
  свыше 1 000:  по договору

Абонемент для компании (несколько мероприятий в год):
  10 мероприятий:  25 000 ₽/год (до 300 чел каждое)
  Безлимит:        60 000 ₽/год

Интеграции корпоративного сценария

Active Directory / LDAP (доменная система)

sequenceDiagram participant AD as Active Directory participant EP as EventPass participant HR as HR-менеджер participant EMP as Сотрудник HR->>EP: Создать мероприятие, импорт из AD EP->>AD: LDAP Search: (objectClass=user), ou=employees AD-->>EP: ФИО, email, отдел, должность, manager EP->>EP: Сгенерировать QR на каждого EP->>EMP: Email / SMS с QR-кодом

Поля, которые читаем из AD:

displayName     → ФИО гостя
mail            → куда отправить QR
department      → для группировки / зон
title           → должность (определяет категорию: vip / standard)
manager         → для VIP-флага (руководитель N-уровня → VIP)
memberOf        → группы (CN=VIP_Corp → vip_guest)

Маппинг групп AD → роли EventPass:

# Настройка в панели организатора
ldap_group_mapping:
  "CN=Board,OU=Groups,DC=company,DC=ru":  vip_guest
  "CN=Staff,OU=Groups,DC=company,DC=ru":  employee
  "CN=IT,OU=Groups,DC=company,DC=ru":     organizer
  "CN=Security,OU=Groups,DC=company,DC=ru": staff_security

Интеграция с 1С:Предприятие

Два варианта: выгрузка из 1С (для импорта участников) и загрузка в 1С (передача данных о посещаемости).

Выгрузка из 1С:ЗУП — список сотрудников

1С:ЗУП → Отчёт → "Список сотрудников" → выгрузить в XML / CSV

Формат XML (стандартный для 1С):
  <Сотрудник>
    <Ид>b3f4a1c2-...</Ид>
    <ФИО>Иванов Алексей Петрович</ФИО>
    <Должность>Директор по продажам</Должность>
    <Подразделение>Отдел продаж</Подразделение>
    <Телефон>+79991234567</Телефон>
    <Email>ivanov@company.ru</Email>
  </Сотрудник>

EventPass принимает:
  POST /api/v1/events/{event_id}/attendees/import
  Content-Type: application/xml  (или multipart/form-data для CSV)

Выгрузка данных из 1С через COM-объект (для прямой интеграции)

Для компаний с выделенным IT:

EventPass предоставляет REST API:
  GET /api/v1/events/{event_id}/attendees
  → JSON: список сотрудников с их статусами

1С обработчик (на языке 1С):
  Соединение = Новый HTTPСоединение("api.eventpass.ru");
  Запрос = Новый HTTPЗапрос("/api/v1/events/" + ИдСобытия + "/attendees");
  Запрос.Заголовки.Вставить("Authorization", "Bearer " + Токен);
  Ответ = Соединение.ПолучитьОтвет(Запрос);

Передача табеля посещаемости обратно в 1С:ЗУП

После корпоратива (если нужен учёт посещения как рабочего дня):

EventPass отчёт → экспорт CSV:
  сотрудник_ид, время_входа, время_выхода, мероприятие

1С:ЗУП обработка:
  Открыть CSV → записать как явку на мероприятие
  (команда выезд, конференция = рабочий день)

Excel — импорт и экспорт

Импорт списка гостей из Excel

Формат: .xlsx / .xls / .csv

Обязательные столбцы:
  ФИО (или Имя + Фамилия отдельно)
  Телефон (для SMS с QR)

Опциональные:
  Email | Отдел | Должность | Категория (vip/standard) | Стол | Доп.примечания

EventPass автоматически:
  → Определяет кодировку (UTF-8, Windows-1251)
  → Валидирует телефоны (форматы: +7..., 8..., 7...)
  → Дедублицирует по телефону
  → Показывает превью перед импортом: "Найдено 285 контактов, 3 дубля, 2 ошибки"

Шаблон Excel (скачивается из панели):

Экспорт результатов в Excel

"Отчёт о посещаемости.xlsx":
  Лист 1: Все участники
    ФИО | Категория | Время входа | Зона | Статус

  Лист 2: Сводка по отделам
