EventPass — облачное решение для мероприятий

Третий продукт семейства TenantPass

Позиционирование

TenantPass — для постоянных объектов с арендаторами. HomePass — для частного дома. EventPass — для временных мест с большим потоком людей и коротким жизненным циклом.

Ключевое отличие: нет постоянной инфраструктуры. Приехал, развернул за 15 минут, отработал, уехал.

Что объединяет все сценарии

1. Регистрация участников (заранее или на месте)
2. Идентификация на входе (QR / RFID / лицо / список)
3. Контроль зон (кто в какую зону может)
4. Учёт присутствия в реальном времени
5. Аналитика (потоки, пики, инциденты)
6. Быстрое развёртывание и свёртывание

Главные требования продукта

  • Облако (российский провайдер) — ничего устанавливать не нужно
  • Мобильное приложение для организатора — весь контроль с телефона
  • Оффлайн-режим считывателей — работают при потере интернета
  • API — интеграция с билетными системами, HR, СКУД-системами площадки
  • White-label — брендирование под организатора
