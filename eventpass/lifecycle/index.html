Жизненный цикл мероприятия

graph LR A([СОЗДАНИЕ]) --> B([ПОДГОТОВКА]) B --> C([РЕГИСТРАЦИЯ]) C --> D([АКТИВНОЕ]) D --> E([ЗАВЕРШЕНИЕ]) E --> F([АРХИВ]) F -->|удаление PII| G([УДАЛЁН]) A:::phase B:::phase C:::phase D:::phase E:::phase F:::phase G:::phase

Фазы и переходы

ФазаДлительностьЧто происходит
СОЗДАНИЕминутыОрганизатор создаёт событие, задаёт зоны и роли
ПОДГОТОВКАдни/недели доИмпорт участников, настройка считывателей, тестирование
РЕГИСТРАЦИЯT-48ч → T-0Участники получают QR, онлайн-чекин открыт
АКТИВНОЕот 1ч до 1месКонтроль входа, реалтайм-дашборд, работа считывателей
ЗАВЕРШЕНИЕT+2чВходы заблокированы, подведение итогов, финальный отчёт
АРХИВ30 днейДанные доступны только для чтения
УДАЛЁНпосле 30 днейPII удалено, агрегаты остаются 1 год

Жизненный цикл участника

stateDiagram-v2 [*] --> invited : импорт / ручное добавление invited --> registered : участник подтвердил и получил QR registered --> checked_in : сканирование на входе checked_in --> inside : вход разрешён inside --> checked_out : сканирование на выходе checked_out --> [*] invited --> cancelled : организатор удалил registered --> cancelled : участник отказался checked_in --> blocked : аннулирован вручную blocked --> [*] inside --> blocked : экстренная блокировка

Жизненный цикл QR-кода

stateDiagram-v2 [*] --> generated : система создала QR generated --> sent : отправлен участнику sent --> active : начало временного окна active --> used : первое успешное сканирование used --> expired : однократный QR (для массовых) used --> active : многократный QR (стройка, корпоратив) active --> expired : истёк срок действия active --> revoked : отозван вручную expired --> [*] revoked --> [*]
