EventPass для массового мероприятия

EventPass для массового мероприятия

Задача

Концерт, фестиваль, выставка, городской праздник. Тысячи человек, несколько входов, VIP-зоны, пресса, волонтёры, охрана. Всё нужно организовать за 2–3 дня, а потом сразу свернуть.

Главная боль: очереди на входе, поддельные билеты, нарушители в VIP-зоне.

Ключевые концепции

QR-код = билет + пропуск

Традиционная схема:
  Билетная система → бумажный билет → на входе оторвали хвостик

EventPass схема:
  Билетная система → webhook → EventPass регистрирует участника
  Участник получает: QR-код в приложении / email / SMS
  На входе: сканирование → мгновенная проверка + разрешение зоны

Категории билетов = зоны доступа

Обычный билет   → fan_zone (партер + трибуны)
VIP-билет       → fan_zone + vip_lounge + early_access
Backstage-пасс  → все зоны включая backstage
Пресс-пасс      → fan_zone + press_pit + media_center
Волонтёр        → staff_zone + fan_zone (без VIP)
Техперсонал     → backstage + technical (без fan_zone в рабочее время)

Ключевые сценарии

Сценарий 1: Быстрый поток на главном входе

Пропускная способность цели: 1 500 чел/час

Организатор расставляет:
  - 8 сканирующих стоек (планшет + QR-сканер)
  - 2 стойки для "проблемных случаев" (менеджер)

Участник подходит:
  → Показывает QR на экране телефона (или распечатанный)
  → Сканер: <500мс → зелёный экран → "Добро пожаловать!"
  → Участник идёт в соответствующую зону

Если QR не работает:
  → Красный экран + причина
  → Участник переходит к стойке менеджера
  → Менеджер ищет по номеру заказа → выдаёт новый QR на месте

Сценарий 2: Контроль зоны VIP

VIP-лаунж — отдельный вход с считывателем:

Участник с обычным билетом пытается пройти:
  → EventPass: ❌ deny — категория "fan", зона "vip_lounge" требует "vip"
  → Экран сканера: "Ваш билет не включает VIP-доступ"
  → Охрана не спорит — система решила

Участник с VIP-билетом:
  → EventPass: ✅ permit
  → "Добро пожаловать в VIP-зону"

Сценарий 3: Аккредитация прессы

До мероприятия (онлайн):
  Журналист заполняет форму: ФИО, издание, фото, тип съёмки
  Организатор одобряет → система генерирует QR-пасс с фото

На входе:
  Охрана сканирует QR:
  → Высвечивается фото журналиста (проверка личности)
  → Категория: "фотограф", зоны: fan_zone + press_pit
  → Отдельный вход для прессы без очереди

Сценарий 4: Многодневный фестиваль

Участник купил билет на 3 дня:
  QR-код работает все 3 дня
  Каждый день: первый вход помечается ("Вход 1/3 дней")
  
Дополнительно: браслет RFID
  День 1: на входе привязали RFID-браслет к QR
  День 2-3: достаточно приложить браслет (без телефона)
  Потерял браслет: отвязать в приложении, привязать новый

Сценарий 5: Отмена мероприятия / форс-мажор

Внезапная отмена:
  Организатор нажимает "Отменить мероприятие"
  → Все QR-коды деактивируются
  → Всем участникам SMS: "Мероприятие отменено. Возврат билетов — ваш провайдер"
  → Все считыватели показывают: "Мероприятие отменено"

Антифрод

Каждый QR-код:
  - Одноразовый: после первого сканирования помечается использованным
  - Содержит: event_id + ticket_id + подпись HMAC-SHA256
  - Валидация: <100мс (Redis кэш активных билетов)

Атаки:
  Скриншот QR и передача другому:
    → Первый вход: ✅
    → Второй вход с той же карточкой: ❌ "Билет уже использован"

  Генерация поддельного QR:
    → HMAC-подпись не пройдёт проверку
    → ❌ "Недействительный билет"
    → Инцидент логируется

Интеграция с билетными системами

Партнёры:
  Яндекс Афиша / Ticketland / Kassir.ru
  → Webhook при покупке билета:
    POST /api/v1/events/{event_id}/attendees
    {
      "ticket_id": "KAS-28347",
      "ticket_type": "vip",
      "buyer_email": "user@mail.ru",
      "buyer_phone": "+79991234567"
    }
    → EventPass генерирует QR и отправляет покупателю

  Собственная продажа (организатор):
    → Импорт списка участников CSV
    → Массовая рассылка QR-кодов

Оборудование

Минимальный комплект (концерт, 500 чел):
  - 2 Android-планшета + Bluetooth QR-сканер + стойки
  - Общая стоимость: ~15 000 ₽ (аренда) / ~25 000 ₽ (покупка)

Средний (фестиваль, 5 000 чел):
  - 10–15 сканирующих стоек
  - 2–3 портативных считывателя для охраны
  - 4G-роутер (резервный канал, если нет WiFi)

Крупный (арена, 50 000 чел):
  - Интеграция со стационарными СКУД-турникетами стадиона
  - 30–50 точек сканирования
  - Отдельный мобильный интернет-канал
