EventPass для магазина / торговой сети

EventPass для магазина / торговой сети

Задача

Контроль персонала в торговой точке: кто вышел на смену, сколько отработал, кто имеет доступ в кассовую зону и склад.

Отличие от TenantPass: нет постоянного IT-отдела, договор аренды может закончиться, персонал меняется каждые 2–3 месяца.

Целевая аудитория

  • Одиночный магазин (5–30 сотрудников)
  • Сеть (до 100 точек, центральный HR)
  • Франшиза (франчайзи не хочет отдельный сервер)
  • Ресторан, кафе, гостиница (аналогичная структура)

Ключевые сценарии

Сценарий 1: Открытие смены

07:45 Кассир Аня подходит к считывателю у входа для персонала
      → прикладывает карту / сканирует QR с телефона
      → EventPass API: проверка графика (смена с 08:00, разрешено за 15 мин)
      → Турникет открывается
      → Таймер смены стартует
      → Push администратору: "Аня открыла смену, пришла в 07:45"

Сценарий 2: Вход в кассовую зону

Кассир Аня идёт к кассе:
      → считыватель на двери кассового периметра
      → ABAC-проверка: role=cashier, zone=cash, time=working_hours → permit
      → Охранник Петров: role=security → кассовая зона → deny

Сценарий 3: Замена кассира из другой точки

Срочная замена: кассир заболел
Администратор сети через мобильное приложение:
  → Поиск кассиров сети по городу
  → Добавление временного разрешения на точку (на 1 смену)
  → Кассир из другой точки приходит по своей карте, доступ работает

Сценарий 4: Ревизия склада

Директор магазина создаёт "ревизионный период":
  → Внешняя команда ревизоров получает QR-коды с доступом только на склад
  → Срок: 2 дня
  → По истечении — автоматический отзыв доступа

Зоны и роли

Зоны магазина:
  floor          — торговый зал (все сотрудники)
  cash           — кассовая зона (только кассиры + старший смены)
  storage        — склад (кладовщик + старший смены)
  office         — кабинет директора (только менеджмент)
  staff_room     — комната персонала (все сотрудники)

Роли:
  cashier        — кассир: floor + cash + staff_room
  stocker        — кладовщик: floor + storage + staff_room
  senior_shift   — старший смены: всё кроме office
  store_manager  — директор: всё
  security       — охрана: floor (наблюдение, не доступ в cash/storage)
  contractor     — подрядчик (уборка, ремонт): временный, floor + staff_room

Табель для сети магазинов

Центральный HR видит:
  По точке:
    Точка "ТЦ Мега, стенд 42"
      Смена 19.10.2026:
        Аня К.       | 07:45 — 20:02 | 12ч 17м | +1ч17м переработка
        Сергей В.    | 08:01 — 16:00 | 7ч 59м
        Мария П.     | 12:00 — 20:00 | 8ч 00м
        Итого отработано: 28ч 16м / план 24ч

  По сети за месяц:
    Общий ФОТ-источник (передаётся в 1С для расчёта ЗП)

Онбординг новой точки

1. Администратор сети создаёт новую точку в веб-панели (10 мин)
   → Вводит адрес, менеджера, зоны
   → Печатает QR-коды для считывателей (или заказывает NFC-считыватели)

2. Добавляет сотрудников:
   → Импорт из 1С (CSV) или вручную
   → Каждый получает SMS со ссылкой на скачивание приложения / своим QR-кодом

3. Считыватель у входа:
   → Планшет Android за 4 000 ₽ + стойка + кронштейн
   → Скачать приложение EventPass Reader, ввести код точки — готово
