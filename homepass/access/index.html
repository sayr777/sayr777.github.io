Сценарии доступа

Хозяин возвращается домой

1. Телефон с BLE / геозона подъезжает к дому
2. Home Assistant обнаруживает приближение за 200 м
3. За 50 м: ворота открываются автоматически
4. Машина въехала → ворота закрываются через 30 сек
5. Подход к двери дома → замок разблокируется
6. Сценарий «Дома»: включается свет в прихожей, отопление переходит в комфортный режим

Гость в гостевом доме

1. Хозяин создаёт PIN-код в приложении: например 4829, действует 3 дня
2. Отправляет гостю через мессенджер
3. Гость вводит PIN на калитке → проходит на территорию
4. Вводит тот же PIN на двери гостевого дома → входит
5. После истечения срока PIN деактивируется автоматически
6. Гость не имеет доступа в основной дом или баню

Уборщица

1. Уборщица имеет постоянную RFID-карту
2. Доступ разрешён: пн-пт, 9:00–18:00, только дом
3. При входе → уведомление хозяину: "Уборщица вошла в дом, 10:23"
4. При выходе → "Уборщица вышла, пробыла 2 ч 15 мин"
5. Если пришла в выходной → отказ + уведомление хозяину

Подрядчик (например, сантехник)

1. Хозяин в приложении: "Добавить подрядчика"
   → выбирает зону (котельная), дату (сегодня), время (10:00–14:00)
2. Подрядчик получает временный PIN
3. В назначенное время PIN работает → доступ только в котельную
4. За пределами времени — отказ
5. После визита PIN автоматически истекает
6. Хозяин получает полный лог визита

Доставка

1. Курьер звонит в домофон
2. Хозяин видит видео на телефоне
3. Нажимает "Открыть калитку" → курьер входит на территорию
4. Оставляет посылку в крытом тамбуре
5. Калитка закрывается через 2 минуты
6. Доступ в дом курьер не получает

Уведомления

Все события доступа → Push на телефон хозяина:

  • Кто вошёл / вышел и куда
  • Неудачная попытка входа (неверный PIN, карта не распознана)
  • Дверь / ворота открыты больше N минут
  • Движение на территории ночью (Frigate)

Fail-safe (при отключении питания / сбое сервера)

ТочкаПоведение при сбое

Дверь домаУмный замок → механический ключ всегда работает
