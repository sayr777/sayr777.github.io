Сигнализация и охранный контур

Сигнализация и охранный контур

Концепция

Три рубежа охраны — каждый следующий означает более серьёзную угрозу:

Рубеж 1 — ПЕРИМЕТР ТЕРРИТОРИИ
  Забор, ворота, калитка
  → обнаружение: кто-то зашёл на территорию без авторизации
  → реакция: тихий алерт

Рубеж 2 — ПЕРИМЕТР СТРОЕНИЙ
  Входные двери, окна, гараж
  → обнаружение: попытка проникнуть в строение
  → реакция: сирена + Push + уведомление соседям

Рубеж 3 — ВНУТРЕННИЙ КОНТУР
  Движение внутри дома когда никого не должно быть
  → обнаружение: уже внутри
  → реакция: сирена + звонок + МВД

Режимы охраны

РежимКогдаЧто охраняется
СнятоВсе дома, деньНичего — только мониторинг
ПериметрВсе дома, ночьТолько рубеж 1 + 2 (снаружи); движение внутри игнорируется
Полная охранаНикого нет домаВсе три рубежа
Тихая охранаХозяин уехал, в доме остались дети / гостиРубеж 1 + 2; внутри — только запись без сирены
ТревогаСработало любое из условийСирена + Push + звонок

Переключение режимов:

  • Автоматически по геозоне (все ушли → полная охрана)
  • Физическая кнопка у входной двери (Zigbee, с PIN)
  • Приложение HA
  • Голосовая команда («Уходим», «Спокойной ночи»)

Сирены и оповещение

Внешняя сирена (уличная):
  - Место: фасад дома, под навесом (защита от дождя)
  - 110–120 дБ, стробоскоп
  - Zigbee или проводное подключение к ESP32
  - Резервное питание: встроенный аккумулятор 12В (работает при отключении света)

Внутренняя сирена:
  - В прихожей
  - Для предупреждения хозяина (тихая) и нарушителя (громкая)

Умные колонки (если есть):
  - TTS-объявление внутри дома: "Внимание! Сработала сигнализация. Контур: окно гостиной"

Логика тревоги

Внешнее проникновение (рубеж 1)

Триггер: PIR сработал на территории + режим "Полная охрана"
           ИЛИ Frigate: person detected + mode != "Снято"

Задержка входа: 0 сек (снаружи — сразу)

Действие:
  1. Включить прожекторы на территории (отпугнуть)
  2. Push хозяину: "Движение на территории у калитки" + фото с камеры
  3. Начать запись всех камер (если не пишут)
  
Если через 30 сек продолжение (человек движется к дому):
  4. Внешняя сирена (3 коротких сигнала — предупреждение)
  5. Push с кнопками: [Тревога ложная] [Вызвать охрану]

Попытка вскрытия (рубеж 2)

Триггер: геркон двери / окна сработал + режим охраны активен

Задержка входа: 30 сек (хозяин мог сам войти и не успел снять охрану)
  → TTS внутри: "Введите PIN или снимите охрану. Осталось 25... 20..."
  → Хозяин снимает охрану в приложении или на кнопке → ничего не происходит

Если PIN не введён / охрана не снята:
  1. Внешняя сирена — полная громкость
  2. Внутренняя сирена
  3. Push всем членам семьи: "ТРЕВОГА: дверь/окно [название] открыто"
  4. Включить весь свет снаружи
  5. Звонок хозяину (не только Push)
  6. Через 2 мин без отмены → уведомить соседей (если настроено)

Вибрация / разбитие стекла (рубеж 2)

Триггер: датчик вибрации / разбития стекла

Задержки нет — сразу:
  1. Внешняя сирена
  2. Push + звонок
  3. Запись всех камер

Движение внутри (рубеж 3)

Триггер: PIR сработал внутри дома + режим "Полная охрана"

Задержки нет:
  1. Внешняя сирена
  2. Push + звонок
  3. Параллельно — автозвонок на номер экстренной службы (если настроено)

Отмена тревоги

Способы:
  1. PIN-код на кнопке у двери
  2. Кнопка в приложении (с подтверждением)
  3. RFID-карта хозяина у считывателя

После отмены:
  - Сирена выключается
  - Push: "Тревога отменена. Кем: [имя], время: 14:23"
  - Запись продолжается ещё 5 мин
  - Событие сохраняется в журнале (нельзя удалить)

Паника и SOS

Тревожная кнопка

Физические кнопки:
  - У кровати в спальне хозяина
  - В ванной (скрытая)
  - Брелок (Zigbee)

Действие при нажатии:
  1. Тихий режим: сирена НЕ включается (не провоцировать нарушителя)
  2. Push всем членам семьи: "SOS от [имя]"
  3. Автозвонок на заранее настроенный номер
  4. Запись всех камер
  5. Включить скрытую запись микрофона (если есть)

Ложная тревога под принуждением

PIN под принуждением (duress code):
  Обычный PIN: 1234 → снимает охрану
  Код принуждения: 1235 (на 1 больше) → внешне снимает охрану,
                   но тихо отправляет SOS + запись включена

Хозяин устанавливает оба кода в настройках HA.

Доступ аварийных служб при тревоге

Автоматически при сработке рубежа 3:

  1. HA генерирует временный токен доступа к камерам (TTL 4 ч)
  2. Push хозяину содержит ссылку для передачи оперативнику МВД
  3. Ворота и калитка разблокируются по команде хозяина
     (или автоматически через 10 мин непрерывной тревоги)
  4. На экране HA — кнопка "Открыть для экстренных служб"

Для передачи диспетчеру:
  - Ссылка на стрим камер (временная)
  - Адрес + код доступа к воротам
  - Схема территории (PDF из HA)

Защита самой системы

Tamper-защита устройств

Датчики Zigbee с tamper-контактом:
  При попытке снять датчик со стены → тревога + Push
  "Попытка снять датчик: окно кухни"

Защита сервера

ИБП: сервер работает при отключении света минимум 1 час
Если питание пропало + тревога активна:
  → Push: "Внимание: электричество отключено во время тревоги"
  → Включить резервный 4G-роутер (если основной интернет от провайдера)

Защита каналов связи

Zigbee — работает локально, не зависит от интернета
Home Assistant — локальный сервер
Push-уведомления при интернете — через WireGuard VPN
Push-уведомления без интернета — SMS через GSM-модуль (резерв)

GSM-модуль (опционально):
  SIM-карта в сервере или отдельном модуле
  При пропадании интернета — SMS хозяину
  Звонок при тревоге рубежа 3

Защита от глушилок (Jammer)

RF-глушилка отключает WiFi и GSM — классическая атака перед взломом.
Детектор: наблюдать потерю связи с Zigbee-устройствами + WiFi.

Триггер: все Zigbee/WiFi устройства пропали одновременно
Действие:
  - Проводная сирена (без радио) включается напрямую
  - Резервный GSM-модуль пробует отправить SMS
  - Запись на локальный NAS продолжается (проводная камера)

Журнал событий

Все события охраны сохраняются с меткой времени и не могут быть удалены пользователем:

2026-10-19 02:34 | Рубеж 1 | PIR у калитки | Режим: Полная охрана
2026-10-19 02:34 | Камера gate | person detected | фото сохранено
2026-10-19 02:35 | Сирена | предупреждение × 3
2026-10-19 02:36 | Push | отправлен хозяину
2026-10-19 02:36 | Тревога отменена | хозяин через приложение
