Видеонаблюдение

Видеонаблюдение

Концепция: запись только по событиям

Не пишем непрерывно. Запись только когда:

  • Чужой человек на территории (AI-детекция: незнакомое лицо или просто человек в зоне без хозяина)
  • Машина въехала / выехала
  • Аварийная ситуация — датчик дыма, утечка воды, сигнализация
  • Ночное движение на периметре

Это экономит место и позволяет быстро найти нужное событие.

Стек

[IP-камеры]  ──RTSP──►  [Frigate NVR]  ──MQTT──►  [Home Assistant]
                              │
                         [Google Coral]  ← AI-детекция объектов
                         (или GPU/NPU)

Frigate — локальный NVR с нейросетевой детекцией (YOLO). Без облака, без подписок. Google Coral USB — аппаратный ускоритель для realtime AI ($60), снимает нагрузку с CPU.

Детекция объектов в Frigate

# Frigate config (пример зоны у калитки)
cameras:
  gate:
    ffmpeg:
      inputs:
        - path: rtsp://192.168.1.101:554/stream1
          roles: [detect, record]
    detect:
      width: 1920
      height: 1080
    objects:
      track: [person, car, cat, dog]
    zones:
      entrance_zone:
        coordinates: 100,200,800,200,800,900,100,900
        objects: [person, car]
    record:
      enabled: true
      events:
        required_zones: [entrance_zone]  # писать только если объект в зоне

Результат: камера пишет только когда человек или машина вошли в определённую зону. Ветка дерева не триггерит запись.

Умный архив

Структура записей:
  /frigate/recordings/
    gate/           ← сегменты по событиям
    perimeter/
    garage/

Retention:
  Событийные клипы (detect): хранить 30 дней
  Непрерывная запись (если включена): 3 дня rolling
  Алертные события (тревога, чужой ночью): 90 дней

Место: 2 TB HDD хватает на 30+ дней событийной записи для 8 камер.

Интеграция с Home Assistant

Уведомление с фото

Триггер: Frigate обнаружил person в gate_zone → MQTT → HA

Действие:
  Push-уведомление на телефон:
    Заголовок: "Движение у калитки"
    Фото: снимок с камеры в момент события
    Кнопки: [Открыть калитку] [Посмотреть видео] [Ложная тревога]

Распознавание «свой/чужой»

Интеграция с Double Take (локальный face recognition):

  • База «своих» лиц: семья, уборщица, регулярные гости
  • Если распознан «свой» → не уведомлять (или тихое уведомление)
  • Если незнакомый → полное уведомление
Frigate → Double Take → HA:
  person: "owner" → уведомление: нет (просто запись)
  person: "unknown" → уведомление: Push с фото

Доступ аварийных служб

Временный удалённый доступ к камерам

При вызове пожарных / скорой / полиции хозяин может открыть временный доступ:

Схема:
  1. Хозяин в приложении: "Открыть доступ аварийной службе"
  2. HA генерирует временную ссылку: https://home.local/frigate/emergency?token=abc123
     действует 2 часа
  3. Ссылка открывает view только конкретных камер (территория, въезд)
  4. Хозяин отправляет ссылку диспетчеру / оперативнику
  5. Через 2 часа ссылка автоматически истекает

Технически: nginx + временный токен в HA → проксирование стрима Frigate

Экстренное открытие ворот для аварийных служб

Хозяин в приложении: "Открыть для аварийных"
→ Ворота открываются + остаются открытыми (не закрываются по таймеру)
→ Push всем членам семьи: "Ворота открыты для аварийных служб"
→ Закрыть вручную после отъезда служб

Автоматика при пожарной сигнализации

Триггер: датчик дыма сработал
Автоматически:
  1. Ворота и калитка открываются (доступ для пожарных)
  2. Все замки дома разблокируются
  3. Камеры переходят в режим непрерывной записи
  4. HA создаёт временный токен и отображает ссылку в интерфейсе

Ночной режим периметра

22:00 → режим "Ночная охрана":
  - Детекция только снаружи (не внутри дома — семья ходит)
  - При любом движении у забора → Push (тихий)
  - При движении у калитки/ворот ночью → сирена + громкий Push
  - Включить прожектор на 30 сек (отпугнуть)

Приватность

  • Камеры внутри дома — только в общих зонах (прихожая, гараж), не в спальнях
  • Внутренние камеры отключаются при появлении дома хозяина (или вручную)
  • Стримы не уходят в облако: всё через WireGuard при удалённом доступе
