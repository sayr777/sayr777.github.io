HomePass — Feature Map

HomePass — Feature Map

БОСС Контроль создан для бизнеса, но домашний проект решает похожие задачи в меньшем масштабе: кто на территории, кто и когда приходил, контроль доступа нанятого персонала.

1. Идентификация людей на территории

Что нужно дома

Семья, гости, уборщица, подрядчики — все входят по-разному.

МетодКто используетСтатус
RFID-карта / брелокСемья, уборщица✅
PIN-код (временный)Гости, подрядчики✅
BLE-смартфонХозяин, семья✅ автооткрытие
RFID-метка на машинеХозяин, семья✅ ворота
Видеодомофон + кнопкаКурьеры, незнакомцы✅
QR-код (разовый)Курьеры при отсутствии✅
Биометрия❌ Избыточно для дома—

2. Журнал посещений (аналог табеля)

Кто пришёл, кто ушёл и когда — для нанятого персонала.

Журнал в Home Assistant:
  10:23 | Уборщица (Мария) вошла | калитка | RFID
  13:01 | Уборщица (Мария) вышла | калитка | RFID
  Итого: 2 ч 38 мин

  14:00 | Сантехник (код 7823) вошёл | калитка | PIN
  15:30 | Сантехник вышел | калитка | кнопка изнутри
  Итого: 1 ч 30 мин

Зачем: спорные ситуации с оплатой. Точное время без «я был 4 часа».

Экспорт

  • PDF / Excel за период
  • Простой — нет интеграции с 1С (не нужна)

3. Реальное время: кто на территории

Виджет в приложении HA:
  ✅ Семья дома: Анна (14:30), Дети (16:00)
  ✅ Персонал на территории: Уборщица (с 10:23)
  ✅ Гости в гостевом доме: Иванов Сергей (с вчера)
  ✅ Подрядчики: нет

4. Физический контроль доступа

Главное отличие от БОСС Контроль — дом умеет открывать двери.

ТочкаУправление
Ворота въездBLE-автооткрытие + кнопка + пульт
КалиткаRFID + PIN + кнопка в приложении
Входная дверь домаRFID + BLE + механический ключ
Гостевой домPIN (индивидуальный на каждого гостя)
БаняRFID + кнопка в приложении
ГаражАвтоматика + кнопка

5. Расписание и временные ограничения

Уборщица:
  Дни: пн–пт
  Время: 09:00–18:00
  Зона: только дом
  При нарушении: отказ + Push хозяину

Подрядчик:
  Конкретная дата + временное окно
  Конкретная зона (котельная, баня, крыша)
  Автоудаление по истечении

6. Уведомления

Адаптированные «табельные» уведомления для дома:

СобытиеУведомление
Уборщица пришлаPush: “Мария вошла в дом, 10:23”
Подрядчик вошёлPush: “Сантехник вошёл через калитку”
Посторонний ночьюPush с фото: “Движение у калитки, 02:34”
Дверь открыта > 5 минPush: “Входная дверь открыта”
Гость не ушёл после valid_untilPush: “Иванов на территории, PIN истёк”
Уборщица в выходной деньPush + отказ в доступе

7. Документы персонала

Упрощённый аналог «просроченных медкнижек»:

Для уборщицы и регулярных подрядчиков:
  Поле "Договор до: 2026-12-31"
  За 14 дней → Push хозяину: "Договор с Марией истекает через 14 дней"
  При истечении → RFID-карта всё ещё работает (не блокируем автоматически,
                   хозяин сам решает)

8. Видеонаблюдение как часть «учёта»

Frigate сохраняет клип при каждом входе/выходе:
  → привязывается к записи в журнале
  → если PIN введён, но лицо не совпадает с привязанным — алерт
  → "Мария вошла: 10:23" + миниатюра кадра

10. Чего нет (и не нужно)

Фича БОСС КонтрольДома
Мультиарендаторность❌ Один дом — одна семья
Интеграция с 1С / ERP❌
Расчёт зарплаты❌ (только время, деньги вручную)
Комплаенс ФСТЭК/ФСБ❌
Корпоративные роли❌ Упрощённо: хозяин / семья / персонал
Масштабирование❌ Один объект, 10–20 человек максимум
