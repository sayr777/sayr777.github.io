ТВ-панель: отчёты, видеоинструкции и анализ событий

ТВ-панель: отчёты, видеоинструкции и анализ событий

Концепция

Телевизор — большой экран в гостиной. По голосовой команде или расписанию он становится:

  • Панелью отчётов (кто приходил, что происходило, энергия)
  • Центром безопасности (события с камер, клипы, фото)
  • Экраном инструкций (как что включить, статус систем)
  • Дашбордом умного дома (температура, присутствие, состояние)

Всё управляется из Home Assistant. Контент генерируется локально.

Видеоинструкции

Голос просит инструкцию → ТВ показывает пошаговое видео или слайды.

Библиотека инструкций

Структура: /ha/www/instructions/
  котёл-розжиг.mp4          ← реальная запись как включить котёл
  котёл-подпитка.mp4        ← как добавить давление
  баня-включение.mp4        ← последовательность действий
  ворота-ручное.mp4         ← как открыть вручную при сбое
  генератор-запуск.mp4      ← запуск резервного генератора
  электрощит-схема.jpg      ← схема автоматов
  трубы-схема.jpg           ← схема водопровода

Запрос инструкции

"Как вручную открыть ворота?"
→ ТВ включается
→ Показывает видео: ворота-ручное.mp4
→ Параллельно голос: "Смотрите инструкцию на экране"

"Как подпитать котёл?"
→ ТВ показывает: котёл-подпитка.mp4
→ Поверх видео — текущее давление из датчика HA: "Сейчас 0.8 бар, нужно до 1.5"

"Где какой автомат?"
→ ТВ показывает: электрощит-схема.jpg (интерактивная)
→ Голос называет нужный автомат по запросу

AI-генерация инструкций (перспектива)

Для устройств без готового видео:
  1. LLM генерирует текстовые шаги (Ollama + llama3)
  2. TTS Piper озвучивает каждый шаг
  3. Слайд-шоу: текст + фото из документации + состояние датчиков

Пример:
  "Как включить тёплый пол в ванной?"
  → HA знает схему подключения (конфиг)
  → LLM: "Шаг 1: проверьте что термостат ванной установлен на…"
  → ТВ: слайд с фото термостата + текущая температура сенсора

Анализ видео и фото с помощью AI

Локальный vision-анализ (Frigate + LLM)

Frigate сохраняет клип и фото при событии
    ↓
Home Assistant триггерит автоматизацию
    ↓
Ollama (LLaVA / Llava-phi3) — vision-модель анализирует кадр:
    "Что происходит на этом фото?"
    → "Мужчина в синей куртке стоит у калитки с посылкой в руках"
    ↓
Описание добавляется к событию в журнале

Примеры анализа

Фото у калитки ночью:
  AI: "Человек в тёмной одежде, стоит спиной, смотрит на забор, 
       похоже проверяет замок"
  → Высокий приоритет уведомления

Фото курьера:
  AI: "Мужчина в жёлтой куртке Яндекс.Доставки держит коробку"
  → Низкий приоритет: курьер

Фото движения в гараже:
  AI: "Кошка на полке"
  → Ложная тревога, пометить автоматически

Еженедельный AI-дайджест

Каждое воскресенье в 10:00:

1. HA собирает все события недели
2. LLM генерирует текстовый отчёт:

   "За неделю 13–19 октября:
    — Уборщица была 3 раза, суммарно 8 ч 15 мин
    — Подозрительных событий: 1 (ночью в среду, вероятно ложная тревога)
    — Энергия: +12% к прошлой неделе (морозы)
    — Котёл: без ошибок
    — Рекомендация: пора обслуживать котёл (работает 340 часов с прошлого ТО)"

3. ТВ включается, показывает дайджест
4. Голосом: краткий пересказ (30 сек)

Технические детали реализации

Cast dashboard на ТВ

# HA automation: голос → ТВ
alias: "Голос: показать события"
trigger:
  - platform: conversation
    command: "покажи кто приходил"
action:
  - service: media_player.turn_on
    target:
      entity_id: media_player.living_room_tv
  - delay: 3s  # ждём включения ТВ
  - service: cast.show_lovelace_view
    data:
      entity_id: media_player.living_room_tv
      dashboard_path: default_view
      view_path: daily-events

Воспроизведение видеоклипа Frigate на ТВ

# Воспроизвести клип события
- service: media_player.play_media
  target:
    entity_id: media_player.living_room_tv
  data:
    media_content_type: video/mp4
    media_content_id: >
      http://192.168.1.100:5000/api/frigate/notifications/
      {{ trigger.payload_json.after.id }}/clip.mp4

Grafana → ТВ

Grafana (отдельный контейнер) строит красивые графики
HA открывает нужный dashboard через Kiosk mode
Chromecast открывает URL: http://192.168.1.100:3000/d/energy/...
