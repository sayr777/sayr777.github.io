Голосовой помощник

Концепция

Полностью локальный голосовой помощник — никакой Алисы, никакого Google Home, никакой отправки голоса в облако. Работает без интернета.

Сателлит в каждой комнате

Схема сателлита (ESP32-S3 DIY):
  INMP441 микрофон (I2S)
  MAX98357 усилитель + динамик (I2S)
  LED-кольцо (статус: слушает / думает / отвечает)
  Питание USB-C

Прошивка: ESPHome + Wyoming Satellite
Связь с HA: WiFi → Wyoming protocol

Стоимость одного сателлита: ~1 500–2 500 ₽

Готовые альтернативы: M5Stack Echo или Home Assistant Voice PE (~$65).

Команды управления домом

Освещение

"Включи свет на кухне"
"Приглушённый свет в гостиной"
"Включи ночник в детской"
"Выключи всё на первом этаже"

Климат

"Какая температура в спальне?"
"Сделай потеплее в гостиной"
"Включи баню" → запускает сценарий прогрева
"Когда баня прогреется?" → "По прогнозу через 1 час 20 минут"

Безопасность

"Кто сейчас дома?" → "Дома Анна и дети. Уборщица ушла в 13:00"
"Открой калитку" → "Открываю калитку на 30 секунд"
"Включи охрану" → "Охрана периметра включена"
"Есть ли кто-то на участке?" → анализ Frigate + ответ

Отчёты (голос → ТВ)

"Покажи кто приходил сегодня"         → включает ТВ + видео-отчёт
"Покажи отчёт по энергии за неделю"   → ТВ + графики
"Покажи последние события с камер"     → ТВ + клипы Frigate
"Кто звонил в домофон вчера?"          → ТВ + фото + время

LLM для сложных запросов

Базовый HA Conversation понимает простые команды. Для сложных вопросов — локальная LLM через Ollama.

Модели (запускаются на сервере):
  Команды управления:   gemma3:4b   (быстро, ~1 сек)
  Сложные вопросы:      llama3.2:8b (медленнее, ~3–5 сек)
  Анализ событий:       llama3.2:8b + контекст из HA

Интеграция: HA extended_openai_conversation → Ollama API

Примеры сложных запросов

"Что случилось дома пока меня не было?"
→ LLM получает: журнал событий за период + состояния устройств
→ Ответ: "Уборщица была с 10 до 13. В 14:23 почтальон оставил посылку.
          Котёл один раз перешёл в экономрежим. Всё в норме."

"Почему сегодня большой расход газа?"
→ LLM анализирует: температура за сутки, время горения котла, открытые окна
→ Ответ: "На улице было -18°C, котёл работал на 40% дольше обычного.
          Норма для такой погоды."

"Кто из чужих заходил на участок на этой неделе?"
→ Frigate события → Double Take (кто знакомый, кто нет)
→ Ответ + фото → на ТВ

Мультиязычность

Языки: русский (основной) + английский
Переключение автоматически по языку фразы-пробуждения:
  "Привет, дом"   → русский Whisper + Piper ru
  "Hey home"      → английский Whisper + Piper en

Контекст разговора

Диалог (не одноразовые команды):

Пользователь: "Включи баню"
Ассистент:    "Баня включена. Прогреется примерно через час двадцать."
Пользователь: "А напомни мне"
Ассистент:    "Хорошо, напомню когда температура достигнет 80°C."
              [устанавливает автоматизацию]

→ 1:25 позже →
Ассистент:    "Баня готова, сейчас 81°C."

Приватность и ограничения

Запись:
  Микрофон активен только ПОСЛЕ wake word
  До wake word — только edge-модель openWakeWord на ESP32
  После ответа — микрофон снова в режиме ожидания

Хранение:
  STT-запросы не логируются (настраивается)
  История команд — локально в HA, 30 дней

Режим "Тихо":
  Физическая кнопка на сателлите — выключить микрофон полностью
  LED: красный = микрофон выключен
