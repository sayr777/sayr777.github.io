Независимость заложена в архитектуре

Каждое техническое решение принято так, чтобы вы не зависели ни от нас, ни от кого-либо ещё.

🔓
Только открытый код

Apache 2.0 / MIT. Подробная документация у заказчика — систему может подхватить любой администратор или разработчик.

🗄️
Данные остаются у вас

Облако, собственный сервер или мультисайт — данные не уходят третьим сторонам.

📡
Работает без интернета

Каждый контроллер хранит кэш разрешений. Дверь откроется даже если сервер недоступен.

🧠
ML из коробки

Биометрия, tailgating-детекция, аномалии доступа, LPR — часть платформы, не надстройка.

🏗️
Модульность

Начинаете с одной двери. Добавляете модули по мере роста без смены платформы.

Российское право

152-ФЗ, 572-ФЗ, ФСТЭК, ТК РФ — закрыты архитектурно, а не по факту нарушения.
