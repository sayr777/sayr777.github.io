ML-архитектура платформы *Pass

Машинное обучение как сквозной слой TenantPass + HomePass + EventPass

Концепция: данные → модели → решения

Три проекта генерируют непрерывный поток данных:

  • Камеры (OpenIPC): видеопотоки 24/7
  • BLE-метки (DN·Beacon): позиции людей в реальном времени
  • LoRaWAN (DN·LoRaWAN): датчики среды
  • СКУД-события: время, точка, результат каждого прохода
  • Энергоучёт: потребление каждые 10 секунд
  • Температура, движение: непрерывные временные ряды

ML превращает этот поток в автоматические решения без участия оператора.

Распределение inference: Edge vs Server

МодельГде работаетПочему
YOLO v8 (СКУД детекция)Сервер (GPU/Coral)Требует >1 GFLOPS
Face recognition (CompreFace)СерверТочность важнее latency
Anomaly detection (СКУД)Сервер10 мс, хватает
LLaVA (описание сцены)Сервер (Ollama)7B параметров
Whisper (STT)СерверMedium модель
Простой thresholdESP32 / RPiНет сети — нет доступа
ONNX классификатор (fraud)Edge RPiОффлайн EventPass

Применение ML по проектам

TenantPass

  • Детекция хвостового захода (tailgating) по камере
  • Аномалии паттернов доступа (сотрудник всегда приходит в 9:00, сегодня в 03:00 → тревога)
  • Биометрическая аутентификация (лицо + карта = 2FA)
  • Прогноз потока на КПП → адаптивное открытие дополнительных проходов
  • Прогноз энергопотребления по зонам

HomePass

  • Распознавание членов семьи (камера + DN·Beacon → точная идентификация)
  • Адаптивная автоматизация: ML учится на привычках (когда включать котёл, свет)
  • Детекция аномального поведения (незнакомый человек ночью на территории)
  • Прогноз когда хозяева вернутся домой → предподготовка дома

EventPass

  • Детекция crowds и очередей: управление потоком
  • Fraud detection: аномальные паттерны сканирования билетов
  • Liveness detection: защита от фото-атаки (пассажир показывает фото QR)
  • Прогноз заполнения зон → превентивное перенаправление потоков
  • Evacuation path optimization: ML выбирает оптимальный маршрут эвакуации

Связи

→ vision → anomaly → forecast → behavioral → inference-stack ← video-surveillance ← dn-beacon ← analytics-pipeline
