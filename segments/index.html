Сегмент 1 — Дом

Кто покупает

ПерсонаОписание
Хозяин дома35–55 лет, есть загородный дом / коттедж / дача. IT-грамотный, самостоятельный. Устал от китайских приложений. Хочет один раз настроить и забыть.
Молодая семьяНовый дом, хочется современно. Бюджет ограничен. Готов часть сделать сам.
Дом с наёмным персоналомДомработница, садовник, охранник. Нужен контроль кто и когда заходит.

Боли

  • Экосистема Xiaomi/Яндекс — всё работает через их облако. Закрыли сервис — всё отключилось
  • Много приложений — одно для замка, другое для камер, третье для климата
  • Безопасность — камеры пишут на зарубежные серверы. Кто смотрит — неизвестно
  • KNX/Gira — стоит как автомобиль, требует сертифицированного монтажника
  • Отсутствие интеграции — свет, замки и отопление не знают друг о друге

Что нужно

Безопасность периметра:   видеонаблюдение + умный замок + сигнализация
Климат:                   котёл по погоде + тёплый пол по зонам + теплица
Освещение:                сценарии (утро / ночь / отъезд / гости)
Контроль доступа:         семья, гости (QR), подрядчики (временный пропуск)
Мониторинг:               температура, затопление, пожар → SMS
Работа без интернета:     всё локально, интернет нужен только для удалённого доступа

Решение — HomePass

Единая платформа Home Assistant. Все устройства — в одном приложении.
Данные — на вашем сервере дома. Никаких подписок, никаких облаков.

Сегмент 2 — Облако (малый и средний бизнес)

Кто покупает

ПерсонаОписание
Владелец кафе / ресторана1–3 заведения, 10–30 сотрудников. Нет IT-специалиста. Нужен контроль прихода/ухода и доступ для подрядчиков.
Управляющий офисом20–100 сотрудников, арендованный офис. Серверной нет и не будет. Нужен табель и пропуска для гостей.
Сеть точек3–15 объектов (магазины, салоны, аптеки). Хочет единый контроль со смартфона.
Прораб / подрядчикСтроительный объект, 30–200 рабочих. Ротация бригад. Учёт по факту для расчёта.
Организатор мероприятийКонцерты, конференции, корпоративы. Каждый раз новый объект.
Коворкинг / бизнес-центрНесколько арендаторов, каждый управляет своими.

Боли

  • Нет серверной — нельзя поставить своё оборудование, нет IT-специалиста
  • Ротация персонала — новый сотрудник каждую неделю, карточки теряются, передаются
  • Несколько объектов — хочется видеть всё в одном окне, а не ехать на каждую точку
  • Поддельные пропуска — охранник не всегда проверяет, карту дали коллеге
  • Споры с подрядчиками — «мои люди работали 300 часов», а по факту 220
  • Цена классических СКУД — PERCo/Parsec требует серверную, монтажника и много денег

Что нужно

Быстрый старт:         зарегистрировался → работает за день, без серверов
Мобильное управление:  добавить/удалить сотрудника с телефона
QR-пропуска:           без карточек — ссылка в Telegram
Несколько объектов:    одна панель управления для всей сети
Простой табель:        кто пришёл, кто опоздал, выгрузка в Excel
Временные пропуска:    гость / подрядчик / курьер на N часов
Цена:                  подписка, не капзатраты

Решение — CloudPass (облачный тариф TenantPass)

SaaS-подписка. Всё в облаке — никакого сервера. Оборудование минимальное.
Подключил считыватель к интернету → начал работать.

Сегмент 3 — Предприятие (Enterprise)

Кто покупает

ПерсонаОписание
IT-директорЗавод, банк, госструктура, крупный ритейл. Требования ФСТЭК. Данные не должны покидать периметр.
Директор по безопасностиРежимный объект. КПП, зонирование, журнал проходов, аналитика инцидентов.
Управляющий гостиницей50–500 номеров. Электронные ключи, ресепшн, парковка, бассейн — всё одной системой.
ДевелоперСтроит бизнес-центр, жилой комплекс, технопарк. Нужна система которую можно продавать арендаторам.
Технический директор ЖКУправляющая компания жилого комплекса. Консьерж-сервис, домофоны, парковка, лифты.

Боли

  • Вендор-локин — Parsec/Sigur сложно заменить, данные в проприетарном формате
  • Нет мультиарендаторности — каждый арендатор требует отдельную систему
  • Нет API — СКУД не разговаривает с 1С, AD, ERP
  • Нет аналитики — только журнал событий, никакого ML
  • Стоимость — 3–10 млн ₽ за систему которая умеет только открывать двери
  • Соответствие законодательству — 152-ФЗ, ФСТЭК, сертификация

Что нужно

On-premise:            данные внутри периметра, нет зависимости от интернета
Мультиарендаторность:  каждый арендатор — своя изолированная система
Интеграции:            1С:ЗУП, Active Directory, LDAP, ERP
ABAC-политики:         время + зона + метод + риск-скор
ML из коробки:         tailgating, аномалии, биометрия, LPR
Зонирование:           сотни дверей, десятки зон, тысячи сотрудников
Compliance:            152-ФЗ, ФСТЭК, ФСБ, ТК РФ
SLA:                   поддержка 24×7, SLA на восстановление

Решение — TenantPass Enterprise

On-premise кластер. Keycloak + PostgreSQL + ML. Полный контроль.
Интеграция с любой корпоративной системой через API.
