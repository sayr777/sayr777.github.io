Что такое DN·LoRaWAN

Промышленные IoT-устройства на Semtech SX1262 + nRF52840 (RAK4631). Протокол LoRaWAN 1.1 OTAA, диапазон RU868 (864–870 МГц). Без SIM-карт и абонентских платежей. Дальность до 20 км, батарея до 10 лет, шифрование AES-128.

ПараметрЗначение
ПротоколLoRaWAN 1.1 OTAA
ЧастотаRU868 (864–870 МГц)
Дальностьдо 20 км в открытой местности
Батареядо 10 лет (ER14505 Li-SOCl₂)
ШифрованиеAES-128 (NwkSKey + AppSKey)
ЧипSemtech SX1262 + nRF52840

Ключевое преимущество: нет WiFi — нет проблем

WiFi (ESPHome):   нужен роутер рядом, ~50 м в помещении
4G (ESP32+4G):    SIM-карта, ~500 ₽/мес абонплата
LoRaWAN:          один гейтвей на 2 км городской застройки
                  покрывает стройплощадку, периметр, удалённые здания
                  без абонплаты, 10 лет батарея

ChirpStack: open-source LoRaWAN Network Server

# docker-compose.lorawan.yml
services:
  chirpstack:
    image: chirpstack/chirpstack:4
    environment:
      POSTGRESQL__DSN: postgres://chirpstack:secret@postgres/chirpstack
      REDIS__SERVERS: redis:6379
      NETWORK__NET_ID: "000000"
      NETWORK__ENABLED_REGIONS: ru868
    ports:
      - "8080:8080"

  chirpstack-gateway-bridge:
    image: chirpstack/chirpstack-gateway-bridge:4
    environment:
      INTEGRATION__MQTT__EVENT_TOPIC_TEMPLATE: "eu868/gateway/{{ .GatewayID }}/event/{{ .EventType }}"
    ports:
      - "1700:1700/udp"   # UDP от гейтвея (Semtech Packet Forwarder)

  # ChirpStack публикует данные в MQTT:
  # topic: application/{app_id}/device/{dev_eui}/event/up
  # payload: JSON с decoded data

Интеграция ChirpStack → Home Assistant

# configuration.yaml (HA)
mqtt:
  sensor:
    # DN·LoRaWAN датчик температуры на удалённом объекте
    - name: "Теплица: температура (LoRa)"
      state_topic: "application/1/device/+/event/up"
      value_template: >
        {% set payload = value_json.object %}
        {{ payload.temperature }}
      unit_of_measurement: "°C"
      device_class: temperature

    # Датчик открытия ворот на дальнем периметре
    - name: "Периметр: ворота открыты (LoRa)"
      state_topic: "application/1/device/abc123def456/event/up"
      value_template: "{{ value_json.object.door_open }}"
      payload_on: "true"
      payload_off: "false"
      device_class: door

# lorawan_bridge.py — универсальный обработчик
import paho.mqtt.client as mqtt
import json

def on_message(client, userdata, msg):
    payload = json.loads(msg.payload)
    device_eui = payload["deviceInfo"]["devEui"]
    data = payload.get("object", {})

    # Маршрутизация по типу данных
    if "temperature" in data:
        ha_client.set_state(f"sensor.lorawan_{device_eui}_temp", data["temperature"])

    if "gps" in data:
        # Обновить GPS-координаты в HA / TenantPass
        lat, lon = data["gps"]["latitude"], data["gps"]["longitude"]
        ha_client.call_service("device_tracker.see", {
            "dev_id": f"lorawan_{device_eui}",
            "gps": [lat, lon]
        })

    if "co_ppm" in data and data["co_ppm"] > 50:
        # Опасный уровень CO → тревога
        ha_client.call_service("notify.all_users", {
            "title": "ТРЕВОГА: CO!",
            "message": f"Уровень CO: {data['co_ppm']} ppm"
        })

mqtt_client = mqtt.Client()
mqtt_client.on_message = on_message
mqtt_client.connect("192.168.1.100")
mqtt_client.subscribe("application/+/device/+/event/up")
mqtt_client.loop_forever()

Стройплощадка (EventPass) без WiFi

Стройка за городом:
  Нет интернета → 4G на ESP32 дорого (SIM-карты × 20 датчиков)
  Решение: один LoRaWAN гейтвей RAK7244 (outdoor, IP67) с 4G backhaul
  + 20+ датчиков DN·LoRaWAN без SIM-карт

  Датчики:
    Температура бетона: DN·LoRaWAN temp × 8 (в опалубке)
    Состояние датчика движения: периметр 500 м
    Уровень топлива генератора: LoRa
    CO2 в бытовках: LoRa
    Счётчик энергии в щитках: LoRa
