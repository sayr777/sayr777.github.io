OpenIPC — прошивка для IP-камер

Что такое OpenIPC

OpenIPC — open-source Linux-прошивка для дешёвых IP-камер на чипсетах Hi3518/Hi3516/GK7205/SSC335. Заменяет закрытую OEM-прошивку на управляемую, предсказуемую, без backdoor’ов.

OpenWrt — WiFi и маршрутизация

Что такое OpenWrt

Open-source прошивка для роутеров и WiFi-точек доступа. Заменяет заводскую прошивку на полноценный Linux с UCI-конфигурацией, поддержкой VLAN, 802.1X, Captive Portal, WireGuard.

Конфигурация VLAN + 802.1X (UCI)

# /etc/config/network — VLAN-интерфейсы

config interface 'loopback'
    option device 'lo'
    option proto 'static'
    option ipaddr '127.0.0.1'
    option netmask '255.255.255.0'

config interface 'vlan_trusted'
    option device 'br-lan.10'
    option proto 'static'
    option ipaddr '192.168.10.1'
    option netmask '255.255.255.0'

config interface 'vlan_iot'
    option device 'br-lan.20'
    option proto 'static'
    option ipaddr '192.168.20.1'
    option netmask '255.255.255.0'

config interface 'vlan_guest'
    option device 'br-lan.30'
    option proto 'static'
    option ipaddr '192.168.30.1'
    option netmask '255.255.255.0'

# /etc/config/wireless — WiFi сети с VLAN

# Доверенная сеть (WPA2-Enterprise / 802.1X)
config wifi-iface 'wifinet_trusted'
    option device   'radio0'
    option mode     'ap'
    option ssid     'HomeNet'
    option encryption 'wpa2'
    option auth_server '192.168.1.X'   # FreeRADIUS
    option auth_secret 'SharedSecret'
    option network  'vlan_trusted'
    option ieee80211r '1'              # Fast Roaming

# Гостевая сеть (WPA2-PSK, изолированная)
config wifi-iface 'wifinet_guest'
    option device   'radio0'
    option mode     'ap'
    option ssid     'Guest'
    option encryption 'psk2'
    option key      'guestpassword'
    option network  'vlan_guest'
    option isolate  '1'                # клиенты не видят друг друга

# IoT-сеть (WPA2-PSK, изолированная)
config wifi-iface 'wifinet_iot'
    option device   'radio1'
    option mode     'ap'
    option ssid     'SmartHome-IoT'
    option encryption 'psk2'
    option key      'iotnetwork'
    option network  'vlan_iot'
    option isolate  '1'

Зональные микрофоны — Silent Monitoring

“Секретные” (скрытые) микрофоны — SIP-endpoint’ы, которые не звонят сами, но к которым можно подключиться из Asterisk для прослушивания зоны.

sequenceDiagram participant HA as Home Assistant participant AST as Asterisk participant MIC as SIP-микрофон\n(зона X) participant SEC as Охрана / монитор note over MIC: Всегда зарегистрирован в Asterisk\nНе звонит — ждёт входящего HA->>AST: AMI Originate: соединить MIC с SEC AST->>MIC: SIP INVITE (входящий) MIC-->>AST: 200 OK + audio stream AST->>SEC: SIP INVITE (к охране) SEC-->>AST: 200 OK AST->>AST: bridge(MIC, SEC) note over SEC: Слышит зону в реальном времени

Конфигурация микрофона в pjsip.conf

; /etc/asterisk/pjsip.conf

[zone-a-mic]
type=endpoint
context=mic-monitoring
disallow=all
allow=ulaw,alaw
transport=transport-udp
callerid="Микрофон Зона А" <3001>
; Нет auth — только с доверенного IP (внутренняя сеть)
direct_media=no

[zone-a-mic-aor]
type=aor
max_contacts=1
qualify_frequency=30

; Аналогично для зон б, в, г...
[zone-b-mic]
type=endpoint
context=mic-monitoring
; ...

extensions.conf — логика мониторинга

[mic-monitoring]
; Микрофон отвечает на входящий звонок и передаёт аудио
exten => s,1,Answer()
same => n,Set(CHANNEL(audioreadformat)=ulaw)
same => n,MixMonitor(/var/spool/asterisk/monitor/${STRFTIME(%Y%m%d%H%M%S)}_${CALLERID(num)}.wav)
same => n,Wait(${MAX_MONITOR_TIME})  ; максимальное время сессии
same => n,Hangup()

[security-monitor]
; Охранник набирает номер зоны → слышит микрофон
exten => 3001,1,Dial(PJSIP/zone-a-mic,60,A(beep))
exten => 3002,1,Dial(PJSIP/zone-b-mic,60,A(beep))
exten => 3003,1,Dial(PJSIP/zone-c-mic,60,A(beep))
exten => 3004,1,Dial(PJSIP/zone-d-mic,60,A(beep))

ChanSpy — скрытое прослушивание активного канала

[security-spy]
; Охранник слушает любой канал незаметно
exten => *90,1,ChanSpy(PJSIP,qw)
; q = тихо (без объявления), w = шёпот (охранник может говорить, другая сторона не слышит)

AMI — запуск мониторинга из Home Assistant

# При тревоге — автоматически открыть прослушку зоны к охране

def monitor_zone(zone: str, security_ext: str):
    ami_action = (
        f"Action: Originate\r\n"
        f"Channel: PJSIP/zone-{zone}-mic\r\n"
        f"Context: security-monitor\r\n"
        f"Exten: {security_ext}\r\n"
        f"Priority: 1\r\n"
        f"Async: true\r\n"
        f"CallerID: Monitor Zone {zone} <9{zone}>\r\n\r\n"
    )
    send_to_ami(ami_action)
