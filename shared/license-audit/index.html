Правило “AGPL firewall”

Любой AGPL-компонент, используемый в SaaS, должен быть изолирован:

[Ваш код] ── REST/HTTP ──→ [AGPL сервис в Docker]
     ↑                              ↑
 Ваша лицензия              AGPL распространяется
 (проприетарная)            только на этот сервис

Нельзя: import lago_sdk в ваш Python-код
Можно: httpx.post(“http://lago:3000/api/…”) из вашего кода
