СценарийРеализация

Dial plan (Asterisk extensions.conf)

[announce-shift-start]
exten => _X.,1,Answer()
same => n,Set(ZONE=${ARG1})
same => n,Playback(shift-start-chime)
same => n,TTS(Начало рабочей смены. Просьба пройти регистрацию на КПП.,ru)
same => n,Hangup()

[alarm-all-zones]
exten => _X.,1,Answer()
same => n,Playback(alarm-signal)
same => n,TTS(Внимание! Тревога. Немедленно покиньте здание через ближайший выход.,ru)
same => n,Hangup()

Home Assistant → SIP-оповещение

# automation: объявление начала смены
- alias: "Объявление начала смены"
  trigger:
    - platform: time
      at: "08:00:00"
  action:
    - service: notify.sip_pa_zone_a
      data:
        message: "Начало рабочей смены. Просьба пройти регистрацию на КПП."

Оборудование дома

Дом:
  Asterisk на том же сервере (Home Assistant / TrueNAS)
  SIP-домофон у калитки (Hikvision DS-KV6113)
  SIP PA-усилитель + потолочные динамики (4 зоны)
  Zoiper на телефонах хозяина (iOS / Android)

Связь:
  Локальная LAN (SIP не уходит в интернет)
  Для удалённого звонка: WireGuard VPN → домашний Asterisk

Автоматизация: гость позвонил в калитку

- alias: "Домофон: звонок в калитку"
  trigger:
    - platform: state
      entity_id: binary_sensor.wicket_doorbell
      to: "on"
  action:
    - service: notify.mobile_app_owner
      data:
        message: "Звонок в калитку"
        data:
          actions:
            - action: OPEN_WICKET
              title: "Открыть калитку"
            - action: SIP_CALL
              title: "Позвонить"
    - service: tts.speak
      target:
        entity_id: media_player.entrance_speaker
      data:
        message: "Подождите, хозяин ответит"

Мобильный PA для мероприятия

  Подключены: WiFi IP-PA колонки (на батареях)
  Управление: веб-панель EventPass → REST → Asterisk AMI

Интеграция со СКУД (TenantPass / EventPass)

sequenceDiagram participant ACS as Агент СКУД participant API as EventPass / TenantPass API participant AST as Asterisk participant PA as PA-система зоны ACS->>API: событие входа (user_id, zone_id) API->>AST: AMI Action: Originate channel=PA/{zone_id} note over AST: TTS: "Добрый день, Иван!\nДоступ открыт" AST->>PA: SIP INVITE → announce PA-->>AST: 200 OK AST->>PA: audio stream (TTS)

Интеграция с сигнализацией (HomePass)

sequenceDiagram participant SENSOR as Датчик тревоги participant HA as Home Assistant participant AST as Asterisk participant PA_ALL as Все PA-динамики participant PHONE as Телефон хозяина SENSOR->>HA: binary_sensor: on HA->>HA: alarm_control_panel → triggered HA->>AST: AMI: broadcast alarm to all zones AST->>PA_ALL: SIP INVITE (multicast / group dial) PA_ALL-->>AST: audio: сирена + TTS HA->>AST: AMI: call owner phone AST->>PHONE: SIP INVITE PHONE-->>AST: owner ответил AST->>PHONE: "Сработала сигнализация. Для отмены введите код."

Важно для соответствия (ФЗ)

  • Оповещение через SIP — не передача ПДн → нет особых требований 152-ФЗ
  • Запись SIP-звонков (если включена) — хранить локально, как переговоры
  • Для объектов КИИ: весь SIP-трафик только в периметре (не через интернет)
