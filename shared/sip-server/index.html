Развёртывание: FreePBX на Docker (HomePass / быстрый старт)

# docker-compose.yml
version: "3"
services:
  freepbx:
    image: tiredofit/freepbx:latest
    container_name: freepbx
    network_mode: host          # SIP требует хостовую сеть (RTP-порты)
    environment:
      - DB_HOST=freepbx-db
      - DB_NAME=asterisk
      - DB_USER=asterisk
      - DB_PASS=strong_password
      - TZ=Europe/Moscow
    volumes:
      - ./freepbx/data:/data
      - ./freepbx/certs:/certs
    restart: unless-stopped

  freepbx-db:
    image: mariadb:10.6
    container_name: freepbx-db
    environment:
      MYSQL_ROOT_PASSWORD: root_pass
      MYSQL_DATABASE: asterisk
      MYSQL_USER: asterisk
      MYSQL_PASSWORD: strong_password
    volumes:
      - ./freepbx/mysql:/var/lib/mysql
    restart: unless-stopped

Основная конфигурация

sip.conf / pjsip.conf — регистрация устройств

; /etc/asterisk/pjsip.conf

; Шаблон транспорта
[transport-udp]
type=transport
protocol=udp
bind=0.0.0.0:5060

[transport-tls]
type=transport
protocol=tls
bind=0.0.0.0:5061
cert_file=/etc/asterisk/certs/server.crt
priv_key_file=/etc/asterisk/certs/server.key

; ===== Домофоны =====
[wicket-doorbell]
type=endpoint
transport=transport-udp
context=doorbell-context
disallow=all
allow=ulaw,alaw,g722
auth=wicket-doorbell-auth
aors=wicket-doorbell-aors
callerid="Калитка" <1001>

[wicket-doorbell-auth]
type=auth
auth_type=userpass
username=wicket-doorbell
password=SomeStr0ngPass!

[wicket-doorbell-aors]
type=aor
max_contacts=1

; ===== PA-усилитель (зона А) =====
[pa-zone-a]
type=endpoint
context=pa-context
disallow=all
allow=ulaw,alaw
callerid="PA Зона А" <2001>

; ===== Softphone хозяина =====
[owner-phone]
type=endpoint
context=internal
disallow=all
allow=ulaw,alaw,g722,opus
auth=owner-phone-auth
aors=owner-phone-aors
callerid="Хозяин" <100>

[owner-phone-auth]
type=auth
auth_type=userpass
username=owner
password=AnotherStr0ng!

[owner-phone-aors]
type=aor
max_contacts=3
qualify_frequency=30

extensions.conf — логика звонков

; /etc/asterisk/extensions.conf

; ===== Домофон калитки =====
[doorbell-context]
exten => s,1,Answer()
same => n,Set(CALLERID(name)=Калитка)
same => n,Playback(beep)          ; звук вызова
same => n,Dial(PJSIP/owner-phone,30,A(beep))
same => n,GotoIf($["${DIALSTATUS}" = "ANSWER"]?answered:noanswer)
same => n(noanswer),Playback(vm-nobodyavail)
same => n,Hangup()
same => n(answered),Hangup()

; ===== PA-оповещение (вызов из HA через AMI) =====
[pa-context]
exten => announce,1,Answer()
same => n,Playback(${ANNOUNCE_FILE})     ; файл готового MP3/WAV
same => n,Hangup()

exten => tts-announce,1,Answer()
same => n,TTS(${ANNOUNCE_TEXT},ru-RU)    ; live TTS (нужен festival/piper)
same => n,Hangup()

; ===== Тревога: обзвон всех PA и хозяина =====
[alarm-broadcast]
exten => s,1,Answer()
same => n,Playback(alarm-signal)
same => n,Dial(PJSIP/pa-zone-a&PJSIP/pa-zone-b&PJSIP/owner-phone,60)
same => n,Hangup()

AMI — управление из Home Assistant / EventPass

AMI (Asterisk Manager Interface) позволяет вызывать команды Asterisk через TCP.

manager.conf

; /etc/asterisk/manager.conf
[general]
enabled=yes
port=5038
bindaddr=127.0.0.1    ; только локально (или VPN)

[homeassistant]
secret=SecretAmIPass!
read=all
write=all
permit=127.0.0.1/255.255.255.0

Пример: HA вызывает PA через AMI (Python)

import socket

def asterisk_announce(zone: str, text: str):
    ami = socket.socket()
    ami.connect(("127.0.0.1", 5038))
    
    # Login
    ami.send(
        f"Action: Login\r\n"
        f"Username: homeassistant\r\n"
        f"Secret: SecretAmIPass!\r\n\r\n"
        .encode()
    )
    
    # Originate — позвонить на PA и воспроизвести TTS
    ami.send(
        f"Action: Originate\r\n"
        f"Channel: PJSIP/pa-{zone}\r\n"
        f"Context: pa-context\r\n"
        f"Exten: tts-announce\r\n"
        f"Priority: 1\r\n"
        f"Variable: ANNOUNCE_TEXT={text}\r\n"
        f"Async: true\r\n\r\n"
        .encode()
    )
    
    ami.close()

TTS-движок для объявлений

Вариант 1: Piper (локальный, русский, быстрый)

pip install piper-tts
# Модель: ru_RU-ruslan-medium (430 МБ)
piper --model ru_RU-ruslan-medium \
      --output_file /tmp/announce.wav \
      --input_text "Начало рабочей смены"

Интеграция с Asterisk: fast-agi скрипт или генерация файла заранее.

Вариант 2: Yandex SpeechKit (облачный)

import requests

def tts_yandex(text: str, output: str):
    r = requests.post(
        "https://tts.api.cloud.yandex.net/speech/v1/tts:synthesize",
        headers={"Authorization": f"Api-Key {YANDEX_API_KEY}"},
        data={"text": text, "lang": "ru-RU", "voice": "filipp", "format": "wav"}
    )
    with open(output, "wb") as f:
        f.write(r.content)

Безопасность

1. SIP внутри LAN — без выхода в интернет
   Мобильный доступ: только через WireGuard VPN

2. TLS-шифрование SIP (порт 5061) для мобильных клиентов

3. SRTP для медиапотоков (RTP → SRTP)
   pjsip.conf: media_encryption=sdes

4. Fail2ban от SIP-брута
   apt-get install fail2ban
   /etc/fail2ban/jail.d/asterisk.conf:
     [asterisk]
     enabled = true
     filter = asterisk
     maxretry = 5
     bantime = 3600

5. Whitelist IP для AMI (только localhost / VPN)
