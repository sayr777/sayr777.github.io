Управление шлагбаумом через ESP32

Большинство шлагбаумов управляются dry contact (сухой контакт реле):

  • Короткое замыкание контакта (100–500 мс) → стрела открывается
  • Второй контакт → принудительное закрытие
# esphome/barrier-entrance.yaml
esphome:
  name: barrier-entrance
  platform: ESP32
  board: esp32dev

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

api:
  encryption:
    key: !secret api_key

# Управление шлагбаумом — dry contact (импульс 500 мс)
switch:
  - platform: gpio
    id: barrier_open_relay
    name: "Шлагбаум — открыть"
    pin:
      number: GPIO26
      inverted: false
    restore_mode: ALWAYS_OFF
    on_turn_on:
      - delay: 500ms     # импульс 500 мс
      - switch.turn_off: barrier_open_relay

  - platform: gpio
    id: barrier_close_relay
    name: "Шлагбаум — закрыть"
    pin:
      number: GPIO27
      inverted: false
    restore_mode: ALWAYS_OFF
    on_turn_on:
      - delay: 500ms
      - switch.turn_off: barrier_close_relay

# Геркон: стрела поднята / опущена
binary_sensor:
  - platform: gpio
    name: "Шлагбаум — открыт"
    device_class: garage_door
    pin:
      number: GPIO34
      mode: INPUT_PULLUP
      inverted: true

  # Петлевой индуктивный датчик: автомобиль под стрелой
  - platform: gpio
    name: "Автомобиль: под шлагбаумом"
    device_class: presence
    pin:
      number: GPIO35
      mode: INPUT_PULLUP
    # НЕ закрывать пока машина под стрелой!

# RFID считыватель для въезда
wiegand:
  - id: rfid_reader
    d0: GPIO4
    d1: GPIO5
    on_tag:
      - homeassistant.event:
          event: esphome.barrier_card
          data:
            card_id: !lambda 'return x;'

# Home Assistant automation: контроль шлагбаума
- alias: "Шлагбаум: открыть по карте"
  trigger:
    - platform: event
      event_type: esphome.barrier_card
  action:
    - variables:
        card_id: "{{ trigger.event.data.card_id }}"
    - if:
        - condition: template
          value_template: "{{ card_id in state_attr('input_text.vehicle_cards', 'value').split(',') }}"
      then:
        - service: esphome.barrier_entrance_barrier_open_relay_turn_on
        - service: notify.mobile_app_owner
          data:
            message: "Въезд: карта {{ card_id }}"

- alias: "Шлагбаум: автозакрытие после проезда"
  trigger:
    - platform: state
      entity_id: binary_sensor.barrier_entrance_car_under_barrier
      to: "off"    # машина проехала
  condition:
    - condition: state
      entity_id: binary_sensor.barrier_entrance_open
      state: "on"  # шлагбаум открыт
  action:
    - delay: "00:00:03"   # 3 секунды буфер
    - service: esphome.barrier_entrance_barrier_close_relay_turn_on

- alias: "Шлагбаум: открыть при выезде (кнопка изнутри)"
  trigger:
    - platform: state
      entity_id: binary_sensor.exit_button
      to: "on"
  action:
    - service: esphome.barrier_entrance_barrier_open_relay_turn_on

Шлагбаум по номеру авто (OpenIPC + Frigate)

Автоматическое открытие по распознаванию номерного знака.

# Frigate: зона распознавания у шлагбаума
cameras:
  barrier_cam:
    ffmpeg:
      inputs:
        - path: rtsp://192.168.30.10:554/stream1
    detect:
      enabled: true
    lpr:           # License Plate Recognition (Frigate+ платная функция)
      enabled: true
      # Или: использовать Plate Recognizer (free tier 2500 вызовов/мес)

# Альтернатива: Double Take + Plate Recognizer
# double-take/config.yml
frigate:
  cameras:
    barrier_cam:
      zones:
        - entrance_zone

plate_recognizer:
  token: YOUR_TOKEN
  regions: ru   # Россия

# HA automation: открыть шлагбаум по номеру
- alias: "Шлагбаум: открыть по номеру авто"
  trigger:
    - platform: mqtt
      topic: "frigate/events"
  action:
    - variables:
        plate: "{{ trigger.payload_json.after.attributes.license_plate }}"
    - if:
        - condition: template
          value_template: "{{ plate in ['А777ВС77', 'В123ЕН99', 'М001КА50'] }}"
      then:
        - service: esphome.barrier_entrance_barrier_open_relay_turn_on
        - service: notify.mobile_app_owner
          data:
            message: "Въезд по номеру: {{ plate }}"

Турникет: управление через ESP32

Большинство турникетов управляются двумя dry contact-входами:

  • Контакт A → разрешить проход влево
  • Контакт B → разрешить проход вправо
  • Геркон → турникет использован (лопасть прокрутилась)
# esphome/turnstile-kpp.yaml
switch:
  - platform: gpio
    id: turnstile_in_relay    # разрешить вход
    name: "Турникет — вход"
    pin: GPIO26
    restore_mode: ALWAYS_OFF
    on_turn_on:
      - delay: 3s   # 3 секунды на проход
      - switch.turn_off: turnstile_in_relay

  - platform: gpio
    id: turnstile_out_relay   # разрешить выход
    name: "Турникет — выход"
    pin: GPIO27
    restore_mode: ALWAYS_OFF
    on_turn_on:
      - delay: 3s
      - switch.turn_off: turnstile_out_relay

binary_sensor:
  # Считыватель входа (Wiegand)
  - platform: gpio
    id: reader_in
    name: "Считыватель входа"
    pin: GPIO4

  # Считыватель выхода
  - platform: gpio
    id: reader_out
    name: "Считыватель выхода"
    pin: GPIO5

  # Пожарная тревога → разблокировать турникет (антипаника)
  - platform: homeassistant
    name: "Пожарная тревога"
    entity_id: binary_sensor.fire_alarm
    on_press:
      - switch.turn_on: turnstile_in_relay   # открыть для эвакуации
      - switch.turn_on: turnstile_out_relay

Применение по проектам

HomePass — ворота + калитка

УстройствоТипУправление
Откатные воротаDoorHan Sliding 500ESP32 + dry contact
КалиткаЭлектрозащёлкаESP32 + Wiegand
Открытие: по BLE телефонаESPresenseHA automation
Открытие: по кнопке в авто433 МГц брелокESP32 + RF receiver
Автозакрытие: через 30 секТаймерHA automation

TenantPass — КПП объекта

Въезд:
  RFID-считыватель на стойке → ESP32 → Keycloak PEP → dry contact → шлагбаум
  Альтернатива: распознавание номера (OpenIPC + Frigate LPR)
  
Выезд:
  Петлевой индуктивный датчик → автооткрытие (выезд всегда открыт)
  Или: RFID-считыватель выезда

КПП пешеходный:
  Трипод PERCo + Wiegand-считыватель + ESP32 → Keycloak PEP

EventPass — входная группа

Стадион / концерт:
  Speed gate × N (параллельные проходы)
  + QR-сканер (ESP32+4G) на каждый проход
  + Полноростовой турникет для секций (антипаника при эвакуации!)

Стройплощадка:
  Трипод + RFID
  Шлагбаум для техники (с петлевым датчиком)

Безопасность: антипаника обязательна

# HA automation: при пожаре — все турникеты открыть
- alias: "Пожар: разблокировать все точки доступа"
  trigger:
    - platform: state
      entity_id: binary_sensor.fire_alarm_system
      to: "on"
  action:
    # Снять питание с электромагнитов (fail-open)
    - service: switch.turn_off
      target:
        entity_id:
          - switch.electromagnet_main_door
          - switch.electromagnet_floor_1
          - switch.electromagnet_floor_2
    # Открыть турникеты
    - service: esphome.turnstile_kpp_turnstile_in_relay_turn_on
    - service: esphome.turnstile_kpp_turnstile_out_relay_turn_on
    # Открыть шлагбаум для пожарных
    - service: esphome.barrier_entrance_barrier_open_relay_turn_on
    # Уведомить всех
    - service: notify.all_users
      data:
        title: "ЭВАКУАЦИЯ!"
        message: "Все выходы открыты. Покиньте здание."
