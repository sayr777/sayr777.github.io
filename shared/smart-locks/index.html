ESPHome — Wiegand + реле + геркон

Универсальный контроллер для любого замка с Wiegand-считывателем.

# esphome/door-controller.yaml
esphome:
  name: door-entrance
  platform: ESP32
  board: esp32dev

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

api:
  encryption:
    key: !secret api_key

# Wiegand-считыватель (26 или 34 бит)
wiegand:
  - id: rfid_reader
    d0: GPIO4
    d1: GPIO5
    on_tag:
      - lambda: |-
          ESP_LOGI("door", "Card: %s", x.c_str());
      # Отправить в HA для проверки
      - homeassistant.event:
          event: esphome.door_card_presented
          data:
            card_id: !lambda 'return x;'
            door_id: "entrance"

# Реле управления замком (12В, нормально открытое реле)
switch:
  - platform: gpio
    id: door_lock_relay
    name: "Замок — входная дверь"
    pin:
      number: GPIO26
      inverted: false
    restore_mode: RESTORE_DEFAULT_OFF

# Геркон — состояние двери
binary_sensor:
  - platform: gpio
    name: "Дверь — открыта"
    device_class: door
    pin:
      number: GPIO18
      mode: INPUT_PULLUP
      inverted: true

  # Кнопка выхода (изнутри — всегда открыть)
  - platform: gpio
    name: "Кнопка выхода"
    pin:
      number: GPIO19
      mode: INPUT_PULLUP
      inverted: true
    on_press:
      - switch.turn_on: door_lock_relay
      - delay: 5s
      - switch.turn_off: door_lock_relay

# Home Assistant automation: проверка карты через Keycloak / список
- alias: "Дверь: проверить карту"
  trigger:
    - platform: event
      event_type: esphome.door_card_presented
  action:
    - variables:
        card_id: "{{ trigger.event.data.card_id }}"
        door_id: "{{ trigger.event.data.door_id }}"
    - choose:
        - conditions:
            - condition: template
              value_template: >
                {{ card_id in state_attr('input_text.authorized_cards', 'value').split(',') }}
          sequence:
            - service: esphome.door_entrance_door_lock_relay_turn_on
            - delay: "00:00:05"
            - service: esphome.door_entrance_door_lock_relay_turn_off
            - service: notify.mobile_app_owner
              data:
                message: "Вход: карта {{ card_id }}"
        default:
          - service: notify.mobile_app_owner
            data:
              message: "Неизвестная карта: {{ card_id }} на {{ door_id }}"

Типы замков по точкам доступа

Электрозащёлка (входная дверь, калитка)

Производители: Abloy EA, Dorcas, SecureEntry
Питание: 12В постоянный ток (200–500 мА)
Управление: реле нормально-разомкнутое
Режим: Fail-Open (при пропадании питания — открыта)

Схема:
  12В БП → реле NO → электрозащёлка
  ESP32 GPIO → реле управление
  При подаче сигнала: реле замыкает → ток на защёлку → открыта
  По таймеру 5 сек: реле размыкает → защёлка закрывается

Электромагнитный замок (офис, коридоры)

Производители: Hikvision DS-K4H250, YLI EM-180
Усилие удержания: 180–600 кг
Питание: 12В / 24В
Режим: Fail-Open (нет питания = дверь открыта)

ВАЖНО для эвакуации: при пожарной тревоге снять питание
→ все электромагниты отпускают → свободный выход

Схема:
  24В БП → нормально-замкнутое реле → электромагнит
  При пожаре: реле размыкается (питание снято) → магнит отпускает

Моторный замок (высокая безопасность)

Производители: CISA 11610, ABLOY EL560, EVVA AirKey
Питание: 12В (мотор при движении засова)
Режим: Fail-Closed (засов остаётся в положении)
Управление: импульс 12В → засов выдвигается/убирается

Схема управления:
  ESP32 GPIO → H-bridge (L298N) → мотор замка
  Открыть: H-bridge в одном направлении
  Закрыть: H-bridge в обратном направлении
  
Или через Wiegand-контроллер замка напрямую.

Умный дедболт (retrofit без вскрытия двери)

Nuki Smart Lock 3.0 Pro:
  Устанавливается поверх стандартного цилиндра
  Управление: BLE / WiFi / Zigbee
  HA: интеграция Nuki + Zigbee2MQTT
  
Yale Linus:
  Аналогично, европейский стандарт
  
Преимущество: механический ключ продолжает работать

TenantPass — СКУД-замки

КПП (турникет): электромагнитная блокировка планки
Офисные двери: электрозащёлка + Wiegand-считыватель
Серверная / касса: моторный замок CISA + биометрия
Аварийный выход: Push-bar (антипаника) + магнитный замок
  → при пожарной тревоге: снять питание всех магнитов

EventPass (стройплощадка)

КПП: электромагнитный турникет / шлагбаум
Опасные зоны: электромагнитный замок на двери
  → открывается только при действующем допуске (инструктаж)
Бытовки: Nuki (не нужна проводка)

Питание замков

12В / 24В источник питания с АКБ (UPS для СКУД):
  Meanwell DR-30-12 (DIN, 12В 2.5А) + АКБ 7 Ач
  → 4–8 часов при потере 220В
  → HA: мониторинг напряжения АКБ через PZEM-017 DC

Токовое потребление:
  Электромагнит 180 кг: 450 мА × 12В = 5.4 Вт
  Электрозащёлка: 200–400 мА × 12В
  Моторный замок (в движении): 800 мА × 12В
