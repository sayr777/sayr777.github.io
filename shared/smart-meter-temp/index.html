ESPHome — однопроводная шина DS18B20

DS18B20 — самый универсальный: водозащищённый корпус, работает в диапазоне −55…+125°C, несколько датчиков на одном проводе.

# esphome/temp-bus.yaml
esphome:
  name: temp-sensors
  platform: ESP32
  board: esp32dev

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

# Шина DS18B20 (один GPIO, до 10 датчиков)
one_wire:
  - platform: gpio
    pin: GPIO4

sensor:
  # Каждый датчик идентифицируется по ROM-адресу
  - platform: dallas_temp
    address: 0x1c3c01d6076bf128   # уличный
    name: "Температура улица"
    unit_of_measurement: "°C"
    device_class: temperature
    update_interval: 30s

  - platform: dallas_temp
    address: 0xf83c01d607923c28   # котёл
    name: "Температура котёл подача"

  - platform: dallas_temp
    address: 0x283c01d607923c29   # котёл обратка
    name: "Температура котёл обратка"

  - platform: dallas_temp
    address: 0x453c01d607923c30   # баня полок
    name: "Температура баня"

  - platform: dallas_temp
    address: 0x673c01d607923c31   # труба хол.воды в гараже
    name: "Температура труба гараж"

  # Вычислить ΔT котла (подача - обратка)
  - platform: template
    name: "Котёл ΔT"
    lambda: >
      return id(boiler_supply).state - id(boiler_return).state;
    update_interval: 30s
    unit_of_measurement: "°C"

ESPHome — BME280 (помещение: темп + влажность + давление)

i2c:
  sda: GPIO21
  scl: GPIO22

sensor:
  - platform: bme280_i2c
    temperature:
      name: "Гостиная — температура"
      oversampling: 16x
    pressure:
      name: "Атмосферное давление"
    humidity:
      name: "Гостиная — влажность"
    address: 0x76
    update_interval: 60s

  - platform: bme680
    temperature:
      name: "Серверная — температура"
    pressure:
      name: "Серверная — давление"
    humidity:
      name: "Серверная — влажность"
    gas_resistance:
      name: "Серверная — качество воздуха"
    address: 0x77

ESPHome — MAX6675 (высокая температура: баня, котёл)

MAX6675 работает с термопарой типа K: диапазон 0…+1024°C, точность ±3°C. Идеально для бани и котла.

spi:
  clk_pin: GPIO18
  miso_pin: GPIO19

sensor:
  - platform: max6675
    name: "Баня — температура камня"
    cs_pin: GPIO5
    update_interval: 10s

  - platform: max6675
    name: "Котёл — температура камеры сгорания"
    cs_pin: GPIO15
    update_interval: 10s

Zigbee-датчики через Zigbee2MQTT

Готовые коммерческие датчики — не нужна пайка, быстрый старт.

# configuration.yaml (HA) — автоматически после сопряжения
# Aqara WSDCGQ11LM создаёт:
#   sensor.aqara_bedroom_temperature
#   sensor.aqara_bedroom_humidity
#   sensor.aqara_bedroom_battery

# Zigbee2MQTT конфиг для сопряжения:
# /etc/zigbee2mqtt/configuration.yaml
permit_join: false
devices:
  "0x00158d0001234abc":
    friendly_name: "Спальня — темп/влажность"
  "0x00158d0001234def":
    friendly_name: "Детская — темп/влажность"

Применение по проектам

HomePass — карта датчиков

Уличный (DS18B20 IP67):
  → морозозащита труб, коррекция котла по погоде

Котёл — подача / обратка (DS18B20):
  → ΔT контроль, КПД, перегрев

Баня — камень / парная (MAX6675):
  → Push когда 80°C, автовыключение при 120°C (пожарная безопасность)

Комнаты (DHT22 / Aqara Zigbee):
  → термостаты тёплого пола, comfort-режимы

Гараж — труба (DS18B20):
  → алерт при T < +2°C → включить подогрев трубы

Гостевой дом (BME280):
  → авто-климат при заезде гостей

Серверная (BME680):
  → перегрев сервера → Push + включить вентилятор

TenantPass — мониторинг офиса

Серверная: BME680 (темп + влажность + VOC)
  → SLA: температура 18–27°C, алерт при выходе
  
Переговорные: Aqara Zigbee × N
  → CO2 + влажность → авто-вентиляция

Электрощит: DS18B20
  → алерт при перегреве клемм (>60°C = аварийная ситуация)

EventPass (стройплощадка)

Бетон / опалубка: DS18B20 × 4 (в массиве бетона)
  → Набор прочности: нужно 5–25°C
  → Push при T < 5°C → включить прогрев (тепловые пушки)
  → Журнал температуры бетона → акт строительного контроля

Бытовка / трубы: DS18B20
  → Морозозащита: T < 0°C → алерт + обогреватель

Автоматизации HA

# Морозозащита труб в гараже
- alias: "Мороз: защита трубы гараж"
  trigger:
    - platform: numeric_state
      entity_id: sensor.temp_garage_pipe
      below: 3
  action:
    - service: switch.turn_on
      target:
        entity_id: switch.heater_garage_pipe
    - service: notify.mobile_app_owner
      data:
        message: "Труба в гараже: {{ states('sensor.temp_garage_pipe') }}°C — обогрев включён"

# Баня готова
- alias: "Баня: готова"
  trigger:
    - platform: numeric_state
      entity_id: sensor.temp_sauna_stone
      above: 80
  action:
    - service: tts.speak
      target:
        entity_id: media_player.kitchen_speaker
      data:
        message: "Баня готова, температура камня {{ states('sensor.temp_sauna_stone') }} градусов"
    - service: notify.mobile_app_owner
      data:
        message: "Баня: {{ states('sensor.temp_sauna_stone') }}°C"

# Перегрев сервера
- alias: "Серверная: перегрев"
  trigger:
    - platform: numeric_state
      entity_id: sensor.temp_server_room
      above: 35
  action:
    - service: switch.turn_on
      target:
        entity_id: switch.fan_server_room
    - service: notify.mobile_app_owner
      data:
        message: "Серверная перегрев: {{ states('sensor.temp_server_room') }}°C"
