ESPHome — PIR (HC-SR501)

Простейший и самый дешёвый вариант. Не фиксирует неподвижного человека.

# esphome/motion-pir.yaml
binary_sensor:
  - platform: gpio
    name: "Коридор — движение"
    device_class: motion
    pin:
      number: GPIO4
      mode: INPUT_PULLUP
    # Задержка снятия: HC-SR501 держит HIGH ~3 сек после движения
    # Для автоматизации освещения достаточно
    filters:
      - delayed_off: 30s   # свет остаётся ещё 30 сек после движения

ESPHome — HLK-LD2410 (mmWave присутствие)

mmWave фиксирует неподвижного человека (работает за столом, спит). Ключевое отличие от PIR.

# esphome/motion-mmwave.yaml
esphome:
  name: presence-office
  platform: ESP32
  board: esp32dev

uart:
  id: ld2410_uart
  tx_pin: GPIO17
  rx_pin: GPIO16
  baud_rate: 256000
  parity: NONE
  stop_bits: 1

ld2410:
  id: ld2410_sensor
  uart_id: ld2410_uart

binary_sensor:
  - platform: ld2410
    has_target:
      name: "Офис — присутствие"
      device_class: occupancy
    has_moving_target:
      name: "Офис — движение"
    has_still_target:
      name: "Офис — статичное присутствие"

sensor:
  - platform: ld2410
    moving_distance:
      name: "Дистанция до движущегося"
      unit_of_measurement: cm
    still_distance:
      name: "Дистанция до статичного"
      unit_of_measurement: cm
    moving_energy:
      name: "Энергия движущегося"
    still_energy:
      name: "Энергия статичного"
    detection_distance:
      name: "Дистанция обнаружения"

ESPHome — HLK-LD2450 (mmWave счёт и направление)

Отслеживает до 3 целей одновременно — можно считать людей в зоне.

# esphome/motion-counter.yaml
ld2450:
  id: ld2450_sensor
  uart_id: ld2450_uart

sensor:
  # Координаты каждой цели (X, Y в мм)
  - platform: ld2450
    target_1:
      x:
        name: "Цель 1 X"
      y:
        name: "Цель 1 Y"
    target_2:
      x:
        name: "Цель 2 X"
      y:
        name: "Цель 2 Y"
    target_count:
      name: "Количество людей"

# Паттерн счёта входа/выхода через коридор:
# target X переходит линию threshold → increment counter

ESPresense — кто именно в комнате

ESPresense работает на ESP32, слушает BLE-маяки телефонов и браслетов (Apple Watch, Mi Band, AirTags, iBeacon).

# esphome/espresense-room.yaml
# Требует fork ESPresense, не стандартный ESPHome
# https://espresense.com/

# HA: создаёт сенсоры типа:
#   sensor.espresense_living_room_iphone_owner   (дистанция в метрах)
# 
# + zone с помощью Node-RED или HA automation:
#   если distance < 3 → person.owner в living_room

# HA: умный свет по присутствию
- alias: "Гостиная: свет по присутствию"
  trigger:
    - platform: state
      entity_id: binary_sensor.living_room_occupancy
      to: "on"
  action:
    - service: light.turn_on
      target:
        entity_id: light.living_room
      data:
        brightness_pct: "{{ 80 if now().hour < 21 else 30 }}"

- alias: "Гостиная: свет выкл при уходе"
  trigger:
    - platform: state
      entity_id: binary_sensor.living_room_occupancy
      to: "off"
      for: "00:05:00"
  action:
    - service: light.turn_off
      target:
        entity_id: light.living_room

TenantPass — подсчёт посетителей и охрана

# TenantPass: счётчики людей по зонам
# HLK-LD2450 на входе каждой зоны → HA MQTT → аналитика

- alias: "СКУД: тревога — движение в нерабочее время"
  trigger:
    - platform: state
      entity_id: binary_sensor.motion_server_room
      to: "on"
  condition:
    - condition: time
      after: "20:00:00"
      before: "08:00:00"
  action:
    - service: notify.mobile_app_owner
      data:
        title: "ТРЕВОГА: серверная!"
        message: "Движение в серверной в нерабочее время"
    - service: camera.snapshot
      target:
        entity_id: camera.server_room
      data:
        filename: "/config/snapshots/server_room_{{ now().strftime('%Y%m%d_%H%M%S') }}.jpg"

EventPass — контроль потоков

# EventPass: считать людей в зонах мероприятия
# LD2450 (3 цели) или Frigate person count → MQTT
# Превышение вместимости → алерт организатору
- alias: "Мероприятие: VIP-зона переполнена"
  trigger:
    - platform: numeric_state
      entity_id: sensor.vip_zone_people_count
      above: 50
  action:
    - service: notify.mobile_app_organizer
      data:
        message: "VIP-зона: {{ states('sensor.vip_zone_people_count') }} чел — лимит 50!"
