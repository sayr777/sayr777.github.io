Tasmota на Sonoff S26 / S31

Sonoff выпускает устройства на ESP8266 — прошиваются Tasmota без пайки.

# Прошивка через tasmota-device-manager (по воздуху, если старый FW позволяет)
pip install tasmota-ota-tool
tasmota-ota --host 192.168.1.XX --file tasmota.bin

# Или через UART (GPIO0 на GND при подаче питания → bootloader)
esptool.py --port /dev/ttyUSB0 write_flash 0x0 tasmota.bin

# Home Assistant: Tasmota интеграция (через MQTT)
# Settings → Integrations → Tasmota (автообнаружение через MQTT Discovery)

# Создаёт сущности:
#   switch.sonoff_s31_desk      — вкл/выкл
#   sensor.sonoff_s31_desk_power   — мощность
#   sensor.sonoff_s31_desk_energy  — потребление

ESPHome — DIY розетка с мониторингом (HLW8012)

Чип HLW8012 — встроен в большинство китайских “умных” розеток.

# esphome/smart-plug-hlw8012.yaml
sensor:
  - platform: hlw8012
    sel_pin:
      number: GPIO12
      inverted: true
    cf_pin: GPIO04
    cf1_pin: GPIO05
    current_resistor: 0.001
    voltage_divider: 2351

    current:
      name: "Розетка — ток"
      unit_of_measurement: A
    voltage:
      name: "Розетка — напряжение"
    power:
      name: "Розетка — мощность"
      unit_of_measurement: W
      on_value_range:
        - above: 2400     # 2.4 кВт — защита от перегрузки
          then:
            - switch.turn_off: relay
            - homeassistant.service:
                service: notify.mobile_app_owner
                data:
                  message: "Розетка: перегрузка {{ x }} Вт — отключена!"
    energy:
      name: "Розетка — потребление"
      state_class: total_increasing

switch:
  - platform: gpio
    id: relay
    name: "Розетка"
    pin: GPIO15
    restore_mode: RESTORE_DEFAULT_OFF

TenantPass — управление оборудованием

# Выключать мониторы через 15 мин после выхода сотрудника
- alias: "Рабочее место: выключить монитор"
  trigger:
    - platform: state
      entity_id: binary_sensor.desk_presence
      to: "off"
      for: "00:15:00"
  action:
    - service: switch.turn_off
      target:
        entity_id: switch.desk_monitor_plug

EventPass — временная инфраструктура

Умные удлинители для временных стендов / стоек:
  → Shelly Pro 4PM в распределительном щитке
  → Выключать оборудование зоны по завершении работы
  → Мониторинг потребления каждой зоны события

Автоматизации HA

# Забытый утюг
- alias: "Утюг: выключить при уходе"
  trigger:
    - platform: state
      entity_id: person.owner
      to: "not_home"
  condition:
    - condition: state
      entity_id: switch.plug_iron
      state: "on"
  action:
    - service: switch.turn_off
      target:
        entity_id: switch.plug_iron
    - service: notify.mobile_app_owner
      data:
        message: "Утюг был включён — выключил автоматически"

# Ночной тариф: зарядка авто
- alias: "Зарядка авто: ночной тариф"
  trigger:
    - platform: time
      at: "23:00:00"
  condition:
    - condition: state
      entity_id: binary_sensor.car_connected
      state: "on"
  action:
    - service: switch.turn_on
      target:
        entity_id: switch.plug_car_charger
