Frigate NVR — ядро системы

Frigate — open-source NVR с встроенным AI-детектором объектов (YOLO).

Принцип работы

sequenceDiagram participant CAM as Камера (RTSP) participant FR as Frigate participant CORAL as Coral TPU participant HA as Home Assistant participant STORE as Хранилище CAM->>FR: непрерывный RTSP-поток FR->>FR: motion detection (CPU, дёшево) FR->>CORAL: кадр при движении → object detection CORAL-->>FR: "person 0.94", "car 0.87" FR->>STORE: запись клипа (только при событии) FR->>HA: MQTT событие: {camera, label, score, clip_url} HA->>HA: запуск автоматизаций

Конфигурация (фрагмент)

# frigate.yml
cameras:
  entrance:
    ffmpeg:
      inputs:
        - path: rtsp://admin:pass@192.168.1.20:554/stream1
          roles: [detect, record]
    detect:
      width: 1920
      height: 1080
      fps: 5
    objects:
      track: [person, car, cat, dog]
      filters:
        person:
          min_score: 0.7
          threshold: 0.8
    zones:
      gate_zone:
        coordinates: 100,200,800,200,800,900,100,900
    record:
      enabled: true
      retain:
        days: 7
        mode: motion
      events:
        retain:
          default: 30
          mode: active_objects

detectors:
  coral:
    type: edgetpu
    device: usb

snapshots:
  enabled: true
  timestamp: true
  bounding_box: true
  crop: true

Облачное хранение:

Frigate развёртывается:
  - Малое мероприятие: ноутбук / мини-ПК организатора (Frigate local)
  - Крупное: арендованный VPS с GPU / edge-сервер на площадке
  - Клипы → S3 EventPass Cloud (тенант-изолированное хранилище)

Расчёт хранилища

Камера 1080p, H.264, motion-only:
  ~500 МБ / день при средней активности
  16 камер × 500 МБ × 30 дней = 240 ГБ

Камера continuous 1080p, H.265:
  ~3 ГБ / день
  8 камер × 3 ГБ × 14 дней = 336 ГБ

Рекомендация: NAS 2-4 ТБ для дома, 8-16 ТБ для объекта СКУД

Распознавание лиц — Double Take

Double Take — прослойка над Frigate, которая сравнивает snapshot с базой известных лиц через CompreFace / DeepStack / InsightFace.

graph LR FR[Frigate\nсобытие + snapshot] --> DT[Double Take] DT --> CF[CompreFace\nлокально] CF -->|"Мария 0.97"| DT DT -->|match: known| HA_K[HA: известный\nнизкий приоритет] DT -->|no match: unknown| HA_U[HA: незнакомый\nвысокий приоритет]

Важно по 572-ФЗ: биометрические шаблоны хранятся локально. Никакой отправки в облако. Для TenantPass корпоративного уровня — отдельная оценка соответствия 572-ФЗ (аккредитованная биометрическая система vs internal).
