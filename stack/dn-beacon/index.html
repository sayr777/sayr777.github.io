DN·Beacon / DN·LoRaWAN

Собственные IoT-устройства

Линейка устройств собственной разработки для нишевых задач платформы: BLE-маяки для бесконтактного доступа и LoRaWAN-датчики для дальнего радиуса.

Почему именно это решение

АспектОписание
DN·PassBLE-пропуск на смартфоне — замена RFID-карте, нельзя потерять
DN·GateBLE-считыватель для ворот и шлагбаумов — IP67, -40°C
DN·ManБраслет для охраны труда на стройке: SOS, геозоны
DN·EvacМаяк эвакуации — точная локализация людей при пожаре
DN·LoRaWANДатчики дальнего радиуса (до 20 км), трекинг техники

Протокол — открытый, совместимый с TTN. Firmware на Zephyr RTOS, обновление по воздуху (OTA).
