OpenMeter

OpenMeter

Usage metering / Биллинг

Измерение потребления для SaaS-биллинга EventPass и CloudPass: количество событий, активные устройства, API-вызовы. Интеграция с YooKassa.

Почему именно это решение

АспектОписание
Event-drivenСчитает события в реальном времени из Redpanda
Stripe-compatible APIЗнакомый интерфейс для разработчиков
Вместо LagoLago перешёл на AGPL — несовместимо с коммерческим встраиванием
ЛицензияApache 2.0

Lago был первым выбором, но AGPL запрещает встраивание в SaaS без открытия кода. OpenMeter — замена.
