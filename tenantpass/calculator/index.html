Калькулятор TenantPass Enterprise — крупный объект

On-premise. Данные внутри периметра. От 460 000 ₽ под ключ.

Для кого

  • Завод, производственный комплекс — от 100 сотрудников
  • Гостиница — от 50 номеров
  • Бизнес-центр класса А/В — несколько арендаторов
  • Жилой комплекс / технопарк / кампус
  • Режимный объект: банк, госструктура, медицинское учреждение
  • Любой объект где данные не должны покидать периметр

Логика ценообразования

Стоимость складывается из четырёх составляющих:

Итого = Оборудование + Работы + (Поддержка × мес) + (Опции)

Оборудование  = базовый сервер + точки доступа + камеры + датчики
Работы        = проектирование + монтаж + настройка + обучение
Поддержка     = опционально (можно самостоятельно)
Опции         = ML-пакет, DN·Beacon, DN·LoRaWAN, резервный кластер

Процесс внедрения

Неделя 1: Технический аудит
  → Выезд на объект, замеры, планирование кабельных трасс
  → Согласование схемы зонирования с заказчиком
  → Коммерческое предложение с детальной сметой

Неделя 2–3: Монтаж
  → Прокладка кабелей, установка замков и считывателей
  → Монтаж камер и серверного оборудования
  → Подключение и тестирование каждой точки

Неделя 3–4: Настройка ПО
  → Keycloak: роли, политики, арендаторы
  → Импорт сотрудников из AD / Excel
  → Настройка ML-моделей под объект
  → Интеграция с 1С (если нужно)

Неделя 4: Запуск
  → Параллельная работа со старой системой (1 неделя)
  → Обучение администраторов и службы безопасности
  → Подписание акта приёмки
  → Гарантия 12 месяцев
