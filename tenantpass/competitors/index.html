БОСС Контроль

Облачная СУРВ (не СКУД!). Терминал → GPRS → облако. «Готово из коробки».

Официально: «Это система учёта рабочего времени, а не контроля доступа — логика систем различна». Двери не открывает.

Отзыв из реального использования: «Контроль можно обмануть. Есть 1000 способов» — именно это мотивирует перенос логики в централизованный policy engine.

PERCo / Sigur / APACS 3000

Классические СКУД с модулем УРВ. Умеют и двери открывать, и табель считать.

Сильные стороны:

  • Готовое железо: отпечатки, вены ладони, лицо, карты, BLE, NFC
  • Гибкие графики, расчёт Т-13, выгрузка в 1С
  • Локальная установка в контуре

Слабость: авторизация = роли внутри СКУД. Гибких ABAC-политик на арендатора / объект / устройство / время нет. Нет единого IdP для всех систем.

Authentik / Casdoor (open-source альтернативы Keycloak)

  • Authentik — проще в развёртывании, современный UI, «Keycloak без головной боли»
  • Casdoor — один Go-бинарник, встроенный RADIUS/LDAP/WebAuthn + Casbin (ABAC из коробки)

Минус: меньше зрелость, меньше сообщество, нет Red Hat SLA для enterprise.

Наша ниша

Прямого конкурента «Keycloak + СКУД как исполнитель + ABAC на арендатора» на рынке нет.

Позиционирование: объекты, где несколько организаций делят одну территорию и физический доступ = учёт работы.
