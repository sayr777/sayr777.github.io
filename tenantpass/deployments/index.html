Варианты развёртывания

Варианты развёртывания

Два режима

Облачное (MVP / SaaS)

graph TD subgraph CLOUD["Российский облачный провайдер"] LB[Балансировщик] KC1[Keycloak node 1] KC2[Keycloak node 2] KC3[Keycloak node 3] DB1[(PostgreSQL primary)] DB2[(PostgreSQL replica)] LB --> KC1 & KC2 KC2 -->|синхронная репликация| KC3 KC1 & KC2 & KC3 --> DB1 DB1 -->|репликация| DB2 end INT[Интернет] T[Терминалы\nGPRS / 4G] GW[API Gateway] INT --> LB T --> GW --> LB

Требования к провайдеру: аттестованный российский облачный провайдер (152-ФЗ локализация). Варианты: Yandex Cloud, Selectel, VK Cloud.

Плюсы:

  • Быстрый старт
  • Нет ИТ-инфраструктуры у заказчика
  • Managed DB + мониторинг провайдера

Минусы:

  • Данные «в облаке» (нужен провайдер с аттестатом)
  • СКЗИ для канала терминал → облако обязательно
  • Недоступно для объектов с требованием «только внутри периметра»

Локальное (On-premise / Enterprise)

graph TD subgraph ONPREM["Контролируемая зона предприятия"] SKZI[СКЗИ-шлюз] LB[Балансировщик] KC1[Keycloak node 1] KC2[Keycloak node 2] DB[(PostgreSQL кластер)] T[Терминалы\nLAN / WiFi] GW[API Gateway] T --> GW --> SKZI --> LB LB --> KC1 & KC2 KC1 & KC2 --> DB end

Плюсы:

  • Данные не покидают периметр → проще соответствие ФСТЭК/ФСБ
  • Нет зависимости от интернета
  • Подходит для ГИС, КИИ, закрытых объектов

Минусы:

  • Нужна ИТ-команда заказчика или наша поддержка
  • Стоимость железа и администрирования
  • Обновления — ответственность заказчика / нашей команды

Многосайтовое (On-premise multi-site)

graph LR subgraph A["Сайт A (объект 1)"] KCA[Keycloak cluster] DBA[(PostgreSQL)] KCA --- DBA end subgraph B["Сайт B (объект 2)"] KCB[Keycloak cluster] DBB[(PostgreSQL)] KCB --- DBB end KCA <-->|"СКЗИ / VPN (sync)"| KCB

Multi-cluster v2: единая синхронно реплицируемая БД, кэши локальные. Требование: commit latency < 5 мс между сайтами.

Стратегия выхода на рынок

  1. MVP → облако (Yandex Cloud / Selectel) + один пилотный объект
  2. Enterprise → on-premise по запросу заказчика
  3. Крупные объекты → multi-site с СКЗИ между площадками
