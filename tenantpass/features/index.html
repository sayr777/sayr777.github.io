TenantPass — Feature Map

TenantPass — Feature Map

За основу взяты фичи БОСС Контроль. Каждая фича оценена: как реализуем, где превосходим, где отстаём.

1. Идентификация сотрудника

БОСС Контроль

  • Лицо, карта, отпечаток пальца на терминале
  • Биометрия обрабатывается локально на терминале

TenantPass

МетодСтатусПреимущество
RFID-карта / брелок✅ Базовый—
Отпечаток пальца✅ Через терминалШаблон хранится только на устройстве (572-ФЗ)
Распознавание лица✅ Через терминалТо же
Passkey / FIDO2✅ СмартфонНет у БОСС; криптографически стойко
NFC-карта (FIDO2)✅Нет у БОСС; защита от клонирования
BLE-смартфон (приближение)✅Нет у БОСС; без касания
QR-код (разовый)✅ Для гостейНет у БОСС

Превосходим: passkey и BLE — бесконтактный вход без физической карты. Защита от клонирования через FIDO2.

2. Отметка прихода и ухода

БОСС Контроль

  • Терминал у входа
  • Данные → облако БОСС → табель

TenantPass

  • Терминал передаёт запрос → Keycloak принимает решение → сервис учёта фиксирует событие
  • Превосходим: решение централизованное, нельзя обмануть (см. отзыв «контроль можно обмануть»)
  • Событие содержит: user_id, door_id, timestamp, method, tenant_id, site_id
  • Все события неизменяемы (append-only журнал)

3. Просмотр присутствия в реальном времени

БОСС Контроль

  • Кто сейчас на месте (по компании)

TenantPass

Для site_manager:

Дашборд "Кто на объекте":
  ✅ Список присутствующих с временем прихода
  ✅ Список отсутствующих (опоздание / не вышел)
  ✅ Фильтр по строению (если несколько зданий на объекте)
  ✅ Фото сотрудника из профиля
  ✅ Уведомление при опоздании > N минут (настраивается)

Превосходим: фильтр по строению (в каком именно здании), т.к. у нас физический доступ через двери. Превосходим: security_officer видит маршрут сотрудника по объекту (через какие двери прошёл).

5. Физический контроль доступа

БОСС Контроль

  • ❌ Отсутствует («Это система учёта времени, а не контроля доступа»)

TenantPass

✅ Открытие дверей, турникетов, шлагбаумов
✅ Управление лифтом (доступные этажи)
✅ Разблокировка ПК при приходе
✅ Зонирование (сотрудник А в зону Б не попадёт)
✅ Временные ограничения (только в рабочие часы)
✅ Ручное открытие охранником
✅ Аварийная разблокировка (пожар, эвакуация)

Это наше главное конкурентное преимущество.

6. Мультиарендаторность

БОСС Контроль

  • ❌ Один клиент = одна учётная запись; нет концепции «несколько организаций на объекте»

TenantPass

✅ Organizations в Keycloak — несколько арендаторов на одном сервере
✅ Полная изоляция данных (tenant_id в каждом запросе)
✅ Каждый tenant_admin управляет только своими сотрудниками
✅ site_manager одного арендатора не видит другого
✅ Общая территория, разные правила доступа для каждого арендатора

9. Расчёт заработной платы

БОСС Контроль

  • Автоматический расчёт ЗП по реально отработанным часам
  • Без переплат за опоздания и ранние уходы

TenantPass

ФункцияСтатус
Почасовая ставка per-сотрудник✅
Расчёт по факту (отработанные часы)✅
Надбавка за ночные / праздники✅
Удержание за опоздания (если нужно)✅ настраивается
