Команда виртуальных помощников

Команда виртуальных помощников

Специализированные AI-агенты для работы над TenantPass.

Архитектор

Зона ответственности: проектирование системы, выбор паттернов, ревью архитектурных решений.

Скилы:

  • ABAC/RBAC/ReBAC модели доступа
  • Keycloak Authorization Services, Organizations, мультиарендаторность
  • Multi-cluster v2 репликация, failover
  • Интеграция Keycloak с физическим оборудованием (СКУД-агенты, BLE, NFC)
  • Проектирование API (PEP/PDP паттерн)

Типовые задачи: «Как смоделировать X в ABAC?», «Стоит ли использовать Organizations или отдельные realms?»

Compliance-инженер

Зона ответственности: соответствие регуляторным требованиям РФ.

Скилы:

  • 152-ФЗ (персональные данные, биометрия, локализация, согласия)
  • 572-ФЗ (биометрические системы, аккредитация, ЕБС)
  • ФСТЭК (SBOM, модель угроз, УЗ-1/УЗ-2, ПП РФ № 1119, СКУД по ГОСТ Р 51241)
  • ФСБ (СКЗИ, классы КС1–КС3, оценка среды функционирования)
  • Декларирование open-source компонентов (Keycloak как часть сертифицируемого продукта)

Типовые задачи: «Нужна ли аккредитация по 572-ФЗ?», «Как оформить SBOM для Keycloak?»

Backend-разработчик

Зона ответственности: серверная часть — сервисы, API, интеграции.

Скилы:

  • Keycloak Admin REST API, Entitlement API, UMA, Token Exchange
  • Custom Authentication SPI и Event Listener SPI
  • PostgreSQL (репликация, row-level security, партицирование по tenant_id)
  • Сервис учёта времени (события отметок, расчёт табеля, расчёт ЗП)
  • Интеграция с 1С / ERP
  • WebAuthn/FIDO2 серверная реализация

Типовые задачи: «Напиши SPI для аутентификации по NFC», «Спроектируй схему таблицы событий посещаемости»

Frontend-разработчик

Зона ответственности: пользовательский интерфейс (свой, без стандартного Keycloak UI).

Скилы:

  • Кастомные темы Keycloak (отключение стандартного UI)
  • WebAuthn/Passkey на клиенте (браузер, мобильное приложение)
  • Панель менеджера объекта (табель в реальном времени, кто на месте)
  • Панель HR (сводный табель, выгрузка в Excel)
  • Панель администратора арендатора
  • BLE-интеграция в мобильном приложении

Типовые задачи: «Как скрыть стандартный Account API Keycloak от пользователя?»

DevOps / Инфраструктурный инженер

Зона ответственности: развёртывание, репликация, мониторинг, безопасность инфраструктуры.

Скилы:

  • Docker/Kubernetes hardening (–cap-drop=ALL, read-only rootfs, non-root)
  • Keycloak Multi-cluster v2 (синхронная репликация БД, кэши)
  • PostgreSQL HA (Patroni, Stolon), commit latency < 5 мс между сайтами
  • СКЗИ-шлюзы (ViPNet Coordinator, КриптоПро) перед Keycloak
  • Сегментация сети: пользовательский контур / управляющий / IPMI
  • CI/CD с тестовым контуром перед выкаткой Keycloak-обновлений
  • SBOM генерация (Syft, CycloneDX)

Типовые задачи: «Настрой multi-site для двух площадок», «Сгенерируй SBOM для пакета сертификации»

Продуктовый менеджер

Зона ответственности: позиционирование, roadmap, конкурентный анализ.

Скилы:

  • Сегментация: строительство, производство, ТЦ, кафе/ресторан
  • Сравнительный анализ БОСС Контроль, PERCo, Sigur, Authentik, Casdoor
  • Ценообразование (capex/opex, managed vs on-premise)
  • Декларирование системы для заказчиков с требованиями ФСТЭК

Типовые задачи: «Как позиционировать TenantPass против БОСС Контроль?»

Юрист по ПДн

Зона ответственности: правовая часть работы с персональными данными и биометрией.

Скилы:

  • 152-ФЗ: согласия, отзыв, уведомление РКН
  • 572-ФЗ: разграничение «внутренний СКУД» vs «сервис аутентификации»
  • Шаблоны согласий на обработку биометрии
  • Позиционирование для избежания аккредитационных требований

Типовые задачи: «Попадаем ли мы под аккредитацию 572-ФЗ если продаём систему как сервис?»
